# 區域圍欄

0.34 版內建錄影格式為 21、模型 0.15.0、API 2.10；CSV 維持 215 欄，沿用曾越界旗標。拒絕舊錄影 1–20，需使用對應舊版本開啟；場景格式 7、相機資料集 5 及原生 SITL 獨立格式 1 不變。586 項測試、實際飛行和獨立重播見 [geofence-zones-v034.json](validation/geofence-zones-v034.json)。

圍欄使用模擬真值的質心，不包含機身半徑；每個 0.005 秒時間步檢查實際端點間線段，不是經校準的連續軌跡或感測器圍欄。設定隨本次實驗、機隊重設及錄影保存，重新載入頁面會回到停用。輪廓為顯示近似，不參與碰撞或相機資料；圓形使用 64 段。

參考 [PX4 v1.17.0 圍欄](https://github.com/PX4/PX4-Autopilot/blob/v1.17.0/docs/en/flying/geofence.md)及 [ArduPilot 允許與禁入圍欄](https://ardupilot.org/copter/docs/common-polygon_fence.html)，未複製其程式碼或聲稱功能與精度相同。

在「管理參數」的「區域圍欄」設定目前選取的載具，新增圓形或簡單多邊形，選擇允許區或禁入區，再按「套用區域圍欄」。此操作不會套用管理視窗中其他參數的草稿，也不會重設實驗；未套用草稿可在關閉視窗或切換載具後繼續編輯。

座標使用世界座標北、東，單位公尺。圓形輸入中心與半徑；多邊形每行輸入一個 `北,東` 頂點，例如 `0,10`。頂點至少三個，邊不可相交或接觸；每機最多 20 區，每個多邊形最多 32 個頂點。座標範圍為 ±500 m，圓半徑為 0.1–500 m。啟用時至少需要一區。關閉可保留區域設定。

允許區取聯集，再扣除禁入區；沒有允許區時只扣除禁入區。允許區邊界可通行，禁入區邊界不可通行。原家點半徑與高度限制仍然生效。設定套用時會檢查家點、起始位置、目前位置和任務航點；不合法則拒絕套用。任務檢查航點，不保證航段不穿越禁區；實際越界會觸發返航，不會規劃繞路。飛行狀態中的「曾越界」會保留到重設。

任務圖與 3D 場景的青綠輪廓為允許區、紅色輪廓為禁入區，顯示目前已套用且啟用的設定，不是實體障礙。3D 輪廓在頂點取樣地形高度並以直線連接；超出地形資料覆蓋時以零高程顯示。重播依時間顯示已錄製設定且不可編輯；外部飛控模式不使用此圍欄。
