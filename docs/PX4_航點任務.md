# PX4 本機航點任務（0.12 版）

此功能已完成指定版本的兩圈原生 SITL 航點飛行與獨立重播驗證。範圍僅限本機 PX4 v1.17.0、`10016_none_iris` 四旋翼及專案的 `node-mavlink` 2.3.0，不是實體飛控或硬體在迴路。

依 [PX4 SITL 操作](PX4_SITL操作.md)啟動本機服務，選擇 PX4，等待版本、飛控狀態及家點就緒；航點使用 `{north, east, altitude, hold}`，數量 1–50，局部北／東及高度為公尺、停留為 0–60 秒，PX4 接受小數。上傳後依 MAVLink 請求送出任務項，再下載逐項核對；ACK 不代表已飛行。開始後須以飛控實際模式、進度、落地與上鎖狀態判斷，不能以畫面真值冒充 PX4 估測。

## 與 ArduCopter 的差異

| 項目           | PX4 v1.17.0                                                                                                 | ArduCopter 4.7.2                                                                 |
| -------------- | ----------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| 任務序號       | 0 起飛；1 至 N 使用者航點；N+1 降落                                                                         | 0 家點；1 起飛；2 至 N+1 使用者航點；N+2 降落                                    |
| 停留時間       | 0–60 秒，可為小數                                                                                           | 0–60 秒整數                                                                      |
| 起飛與降落位置 | 家點起飛至首航點高度；最後航點位置降落                                                                      | 家點起飛至首航點高度；最後航點位置降落                                           |
| 完成證據       | PX4 當次任務 ACTIVE、曾解鎖及離地、使用者航點到達、飛控 COMPLETE 和在地、兩種解鎖狀態皆已解除、模型穩定在地 | 使用者航點到達、最後 LAND 曾被選中、曾解鎖及離地、飛控在地且已上鎖、模型穩定在地 |

PX4 完成先前任務後，重新設定目前項至 0 可能仍回報前次 `COMPLETE`（5）；新一趟飛行仍須觀察到當次 `ACTIVE`（3）及離地後的完成證據，不能把舊 COMPLETE 當成新任務完成。ArduCopter 的最終 LAND 不一定發送到達訊息，上鎖後序號可能回到 1；不將此行為套用至 PX4。詳見 [ArduPilot 航點任務](ArduPilot_航點任務.md)。

PX4 以同一來源回報 `MISSION_CURRENT`、`MISSION_ITEM_REACHED` 及 `EXTENDED_SYS_STATE`，完成時仍需確認新鮮的 heartbeat、模式及地面／上鎖狀態。`MISSION_START` 是 300，會要求 AUTO_MISSION 與正常解鎖，ACK 只表示命令處理結果。飛控的健康與位置檢查保持啟用；請依實際拒絕訊息等待暖機或修正問題。

## 隔離與記錄

PX4 模擬感測器與執行器使用本機 TCP 4560；任務 MAVLink 只使用受控 loopback UDP 14560／14561，並使用 [PX4 loopback 修補](../companion/patches/README.md)。這不是通用地面站或遠端控制服務。模擬仍以 250 Hz（4 ms）運行；PX4 紀錄仍是獨立 `flight-lab-px4` 版本 1，不是內建 schema 14。回放僅重演物理輸入，不重跑 PX4。

來源參考 [PX4 v1.17 Commander](https://github.com/PX4/PX4-Autopilot/blob/v1.17.0/src/modules/commander/Commander.cpp)、[任務通訊實作](https://github.com/PX4/PX4-Autopilot/blob/v1.17.0/src/modules/mavlink/mavlink_mission.cpp)與 [MAVLink 任務協定](https://mavlink.io/en/services/mission.html)。Context7 無該精確版本索引，已用標籤原始碼及安裝的 node-mavlink 2.3.0 訊息定義核對。模型未實機校準，測試結果不能作為實際飛行或安全認證。

## 原生測試與獨立重播

指定 PX4 版本以同一四航點任務完成兩圈；首點停留 0.5 秒，其餘各 1 秒。第一圈 48.652 秒模擬、63.516 秒牆上時間；第二圈在 86.228 秒收到 COMPLETE，86.616 秒確認飛控在地、已上鎖及物理模型穩定。兩圈均收到 0–5 的到達訊息，第二圈觀察到新的 ACTIVE；下載任務識別碼與飛控 missionId 一致。

獨立重播兩圈紀錄，核對 21,649 個執行器輸入、14 個啟動步數及 1,733 個樣本，位置、四元數及馬達最大誤差均為 0。檔案雜湊與結果見[精簡驗證資料](validation/px4-auto-mission-v012.json)。瀏覽器另完成上傳、逐項下載核對、修改草稿後禁止開始及恢復草稿後重新啟用，並完成實際任務與落地；匯出的紀錄獨立重播結果亦見該驗證資料。停止並返回內建模擬後，原先時間、樣本與草稿均保留。這些結果限於測試條件，不代表實機校準。
