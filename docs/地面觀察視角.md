# 地面觀察視角

飛行空間工具列的「地面觀察」提供固定地面觀察點，鏡頭會追蹤目前的飛行器。選擇「觀察視角設定」可輸入北向 N、東向 E（各 ±500 m）、離地眼高（0.5–10 m）及垂直視角 FOV（15–100°），再按「套用並切換地面視角」。設定不會重設飛行，暫停、重播與本機飛控模式也能使用。

眼高是觀察點相對當地地表的高度；垂直 FOV 是鏡頭光學視角，並不改變眼睛的位置。狀態列顯示固定眼點的 NED 座標、離地眼高、FOV 與到飛行器的距離。沒有自動變焦、行走或人物模型；在此視角下不提供自由旋轉和縮放控制。

使用 DEM 時，觀察點必須位於地形涵蓋範圍；無法套用的設定不會覆寫已儲存設定。若切換地形後觀察點不再受涵蓋，畫面會切回自由視角並提示。設定儲存在目前瀏覽器，供所有實驗使用，不寫入飛行紀錄。此功能只影響觀看畫面，不改變飛行模型、機載感測器影像或資料格式。
