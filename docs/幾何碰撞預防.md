# 幾何碰撞預防

這項功能在內建模擬的位置控制中，根據已知障礙盒、NIST 器材網格及其他載具的包絡預測水平運動，必要時限制速度目標並要求煞停。它不直接改寫載具真實位置或速度，也不規劃繞路。這是未經實機校準的教育模型，不能保證避免碰撞。

## 操作

在管理區「幾何碰撞預防」為目前選取的載具啟用功能，設定安全餘量（0–20 m）、反應延遲（0–5 s）及煞車加速度（0.1–3 m/s²），再套用參數。各載具設定獨立，設定於本次飛行保留；重新整理頁面後須重新啟用。預設為關閉、餘量 1 m、延遲 0.6 s、加速度 2 m/s²。僅改此項設定不會重設實驗；同時變更飛行模型或虛擬感測器時仍依原有流程重設。

飛行管理區顯示關閉、等待位置控制、正常、減速中或餘距不足，以及設定的安全餘量。餘量是設定值，不是量測的實際障礙距離；即使顯示正常也不能保證不碰撞。姿態模式可保留啟用設定，但功能只有位置控制可作用。固定翼及外部飛控不支援啟用；VTOL 只能在完全懸停時啟用，啟用後須先關閉才能切換巡航。

## 範圍與資料

功能使用模擬世界已知幾何真值，不讀取 LiDAR 或六向近接感測器，無未知障礙、地形或繞路保障；障礙移動、執行器限制及物理誤差仍可能使煞停不足。六向近接量測維持獨立觀察與警示，不控制飛行。

設定記於各載具 `setup.collisionPrevention`，變更以 `collisionPrevention` 事件記錄。關閉時狀態為 `null`；啟用時提供適用與作用狀態、原因、障礙類型與識別、期望及限制後的水平速度、指令加速度和設定餘量。內建紀錄使用 schema 22、模型 0.16.0、CSV 共 222 欄；同頁 API 為 2.11，場景格式 7、相機資料集 5 不變。舊版內建紀錄不自動轉換。

## 驗證

562 項測試通過，包含四種可懸停機型的真實物理軌跡、轉向曲線、迎面雙機、高架障礙、NIST 共用網格、完整停止尾段及數值邊界。瀏覽器使用同一面牆：關閉時實際撞牆；開啟後保留北向 20 m 目標並在牆前制動。該次長段飛行最小機體表面餘距約 4.82 m，大於設定的 1 m；不是保證所有條件可維持此距離。

已核對單獨設定不重設飛行、同時改模型保留新設定、多機設定與未套用草稿、固定翼拒絕，以及 JSON 往返與 222 欄 CSV。390 px 寬度沒有水平溢位。PX4 與 ArduCopter 均完成起降、60 秒懸停及獨立重播回歸；原生模式的碰撞預防保持關閉。

原始資料雜湊、重播誤差及測試範圍見 [collision-prevention-v033.json](validation/collision-prevention-v033.json)。瀏覽器重播沿用原有 1e-9 門檻，沒有擴大容差。

設計參考 [PX4 v1.17.0 碰撞預防文件](https://github.com/PX4/PX4-Autopilot/blob/v1.17.0/docs/en/computer_vision/collision_prevention.md) 的減速與停止概念；本功能使用已知幾何，並非等同 PX4 的感測器碰撞預防。
