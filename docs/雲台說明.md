# 理想三軸雲台（0.13 版）

0.26 的模型 0.11.0 在關節限制內解析擬合目標姿態，保留硬止擋與逐軸限速；極點同姿態選擇最短關節移動。Euler 關節座標在極點附近病態，物理姿態應以旋轉矩陣理解，不能保證所有平台及任意角度的關節重播一致。初始模型 0.10 候選的重播失敗及修正驗證範圍見[飛行模型說明](飛行模型說明.md)；419 項測試與實際影像、長時間重播驗證見[0.26 驗證摘要](validation/automatic-camera-v026.json)。這是教育用途的運動學模型，未經實機校準。

先前單機版本的瀏覽器三影格拍攝與資料集往返曾驗證；0.20 多機瀏覽器驗證已完成。預設為 `mode: "body"`，`target: {yaw: 0, pitch: π/12, roll: 0}`，`maxRate` 三軸均為 π/2 rad/s。完整設定形狀為 `{mode, target: {yaw, pitch, roll}, maxRate: {yaw, pitch, roll}}`，`mode` 為 `body` 或 `ned`。雲台提供機體座標及 NED 世界座標方向目標，依模擬時間推進 yaw、pitch、roll 三個關節，並回報實際角度、限位、限速與追蹤誤差。角度使用弧度，最大角速度可設 1–360 度／秒；機械角度範圍為 yaw ±π、pitch ±π/2、roll ±π/4。機體為 FRD，正 yaw 向右，正 pitch 向下，組合順序為 `Rz(yaw) × Ry(-pitch) × Rx(roll)`。世界目標受關節極限與角速度限制，不能保證任何情況下都精確跟隨。yaw 不會穿過機械止擋作環繞；極點處選擇最接近先前關節姿態的可行組合。暫停時姿態不推進，設定目標不會令實際角度瞬移。

拍攝使用實際關節姿態，RGB、平面深度和分類共用影格姿態與時間。飛行紀錄 schema 22 保存初始設定、雲台事件及採樣實際狀態，不接受版本 1–21；相機資料集版本 5 獨立保存每影格雲台及姿態，不接受資料集版本 1–4。飛行模型版本為 0.16.0。外部 PX4／ArduPilot SITL 使用固定機體預設，停用雲台控制，沒有 MAVLink 雲台介接。

此為理想運動學近似，不代表真實馬達、振動、延遲或經校準的攝影設備，也不表示實體硬體或飛控雲台已驗證。世界姿態追蹤可能因極點及限位受限，應檢查狀態，而非假設目標已達成。

參考 [AirSim 相機穩定設定](https://github.com/microsoft/AirSim/blob/main/docs/settings.md)、[ArduPilot SITL 雲台模型](https://github.com/ArduPilot/ardupilot/blob/master/libraries/SITL/SIM_Gimbal.cpp) 及 [PX4 雲台控制](https://github.com/PX4/PX4-user_guide/blob/main/en/advanced/gimbal_control.md)；本模型採用獨立的簡化設計。

各架飛行器有獨立雲台設定；程式介面以 `getGimbal(vehicleId)` 與 `setGimbal(vehicleId, settings)` 指定載具。`snapshot.gimbal` 包含設定及 `actual: {yaw, pitch, roll}`、每軸布林值 `limited`、`rateLimited`，和 0–π 的 `trackingErrorRad`。所有角度與角速度分別以 rad、rad/s 表示。

schema 22 每個樣本將狀態壓縮為 `[yaw, pitch, roll, limitedMask, rateLimitedMask, trackingErrorRad]`；兩個遮罩的 bit 0、1、2 依序代表 yaw、pitch、roll。設定記於初始 setup 與雲台事件，讀取驗證時還原完整物件；樣本省略 airframe 與 attitude，分別由該載具初始設定的 config.airframe 及同一 bodyToNedAngles(quaternion) 還原，以節省容量；相機資料集版本 5 每影格直接保存完整雲台狀態及姿態。遙測 CSV 為 222 欄，前兩欄為載具 ID 與世界 tick，其中雲台追加模式、目標、最大速率、實際角度、限位／限速旗標及追蹤誤差共 17 欄。

先前單機版本的歷史驗證包含 30 分鐘／約 96 MiB 容量邊界，歷史紀錄不能匯入現行 schema。瀏覽器拍攝三影格的 RGB、深度與分類，資料集匯出、匯入、再匯出逐位元組一致；schema 8 記錄 309 樣本與兩筆雲台事件，Node 驗證往返一致。瀏覽器重播終點已確認顯示最後一筆 15.395 秒（畫面四捨五入為 00:15.40），控制維持唯讀。獨立依事件重跑 309 個樣本，位置最大差約 5.7×10⁻¹⁴ m、雲台角最大差約 5.0×10⁻¹⁶ rad。數據與檔案雜湊見[驗證資料](validation/gimbal-v013.json)。
