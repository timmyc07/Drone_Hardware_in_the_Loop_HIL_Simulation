# 前向幾何雷達

每架載具的雷達固定在物理質心，朝機體前方，與雲台無關。它使用水平與垂直角度網格，在每條射線保留最近回波；地形、障礙盒及其他載具的保守包圍球會遮擋後方，自己的包圍球不參與。這是幾何模型，沒有電波傳播、RCS、材質、反射強度、多重路徑、天氣影響、實機校準或目標識別；資料不輸入內建或外部飛控。

讀數有 `time`、`valid`、`reason`、量測時 `positionNed`、`quaternion`（wxyz）、`velocityNedMps`、射線數、視角、距離範圍等欄位及 `detections`。每個回波包含射線索引 `beam`、距離 `rangeM`、機體前向的方位 `azimuthRad`、仰角 `elevationRad` 與距離變化率 `rangeRateMps`。方位向右為正、仰角向上為正；距離變化率正值為遠離、負值為靠近。速度包含自機平移：飛向靜止牆面時為負，不應將靜止牆一律顯示成零。角度為弧度，距離與速度分別為 m 和 m/s；NED 表示北、東、下。

預設 10 Hz、水平 31 × 垂直 9 條射線、水平／垂直視角 60°／20°、範圍 0.2–100 m；距離雜訊標準差 0.05 m、速度雜訊標準差 0.05 m/s。最多 3,321 束。參數按載具設定，與其他感測器共用延遲及丟包設定；故障也按載具設定。延遲讀數保留取得時刻與姿態，齡期是目前模擬時間減取得時間；尚未量測或故障可能沒有姿態。無回波不代表故障。

感測器工作台顯示俯視扇形及最近 100 筆回波；匯出保留全部回波。橙色表示靠近，青色表示遠離或零。重播顯示所選載具當時保存的讀數並允許匯出，但不能修改故障或設定。

JSON 為 `{format: "flight-lab-radar", version: 1, sourceVehicleId, exportWorldTick, frame: "NED", detectionFrame: "FRD", units: "m", config, reading}`。CSV 每筆回波一列，附來源、匯出 tick、量測時刻與取得姿態／速度；零回波時保留一筆空點資料列與 metadata，不造假回波。`exportWorldTick` 是匯出當下世界時間步，可能晚於延遲讀數的取得時刻。API `window.flightLab.exportRadarData(vehicleId, "json" | "csv")` 回傳 `{format, sourceVehicleId, exportWorldTick, time, detectionCount, text}`；預設 JSON。API 在重播或外部飛控模式拒絕操作，UI 可匯出所選重播影格。

飛行紀錄 schema 16 將各載具雷達讀數及設定保存於世界感測器影格及事件；模型版本為 0.11.0。場景為版本 6、相機資料集為版本 5，外部 SITL 紀錄維持獨立版本 1。已完成雙機靠近、遠離、延遲、故障及恢復的瀏覽器驗證與獨立重跑；解析幾何與速度的測試最大誤差為 0，結果限於該測試條件。

參考 [CARLA 0.9.16 雷達文件](https://carla.readthedocs.io/en/0.9.16/ref_sensors/)與固定版本 [雷達實作](https://github.com/carla-simulator/carla/blob/294096eb1c38eabf246e4f3a9cdab704e33a7f4c/Unreal/CarlaUE4/Plugins/Carla/Source/Carla/Sensor/Radar.cpp)（CARLA 程式使用 MIT 授權）。CARLA API 文字將速度描述為朝向感測器，實作以目標減感測器速度投影至射線；本專案明確採距離增加為正，請依本文件判讀，兩者不可只憑名稱假定相同符號。本專案沒有複製 CARLA 程式。

壓縮紀錄以八位元保存各感測器故障旗標；雷達採六欄陣列保存取得時間、狀態代碼、NED 位置、姿態、速度及回波，狀態代碼為 0–4。延遲與丟包保留取得姿態與速度，解碼時還原完整讀數。schema 16 嚴格拒絕版本 1–15；30 分鐘／約 96 MiB 的全隊資料上限不變，30 分鐘測試案例耗時 34.31 秒。

雷達亂數狀態由 seed 經固定 XOR 常數獨立產生，不改變既有六種感測器的亂數序列；舊六種感測器的 golden 測試逐位元一致。八機、每機 3,321 束、20 Hz 的核心測試約 0.376 倍即時速度，不能視為硬即時保證。
