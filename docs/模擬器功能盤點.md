# 無人機模擬器公開功能盤點

查核日期：2026-11-05。這是依公開官方產品頁、文件、開源倉庫及政府資料整理的代表性目錄，不是市場或專有系統的完整功能清單。每一筆功能資料保留原始來源網址；產品提供功能不代表本專案已提供同等精度或完整度。

## 方法與界線

先搜尋 GitHub 上既有開源技術，再核對供應商及專案文件。每項以可追溯功能概念表示，狀態只描述本專案：`implemented` 為既有功能、`partial` 為部分完成、`planned` 為尚待開發、`external` 為需要外部系統或服務；狀態不得視為外部產品的聲明。本專案基本功能依模組與自動測試結果更新；介面實機與手把硬體仍需驗證。資料位於 `web/capabilities.js`，不在執行時抓取網頁。

本盤點以飛行訓練、研究與非武器化感測器操作為範圍；不納入武器、攻擊規劃及目標處置。受限與未公開的能力均屬未知，不推測軍用產品內部功能，也不建立籠統「軍用模式」。視覺天氣與 FPV 畫面不是經校準的感測器模型；既有 PID 亦使用理想狀態觀測，不能等同實體飛控。

## 分類與缺口

飛行模型、控制與航行、環境、感測與通訊、故障與安全、訓練與評估、資料與整合共七類。目前具備基本航點、返航、位置控制、視覺天氣、故障注入、六種練習（依機型限制）、七種簡化感測器、機載相機影像與同頁 JavaScript API；其範圍與限制請參見各項描述。經校準的固定翼與 VTOL 氣動模型、經校準的相機模型、完整場景三維光達／雷達資料、廣域 GIS 地形、實體飛控硬體迴路、多人及教學管理目前均非現成功能。雨霧視覺效果不等同真實天氣或感測物理。外部產品的授權、平台、版本與可用性須另行確認。

## 建議開發順序

1. 驗證現有操控、任務、障礙、練習和重播的端到端行為及實體手把。
2. 擴大 PX4／ArduPilot SITL 及感測器驗證，評估實體 HIL。
3. 依需求開發固定翼與 VTOL 氣動模型及地理資料。
4. 評估多人和教學管理；外部能力須有實際整合與授權。

## 本專案目前狀態

目錄共 70 項：已實作 8、部分實作 51、規劃 3、需外部系統 8。此數字代表目錄條目數，並非市場功能覆蓋率；部分實作的精度和範圍見各項描述。模型使用理想狀態加雜訊，無 GPS／EKF；電池電壓降不會降低馬達推力；障礙碰撞採依機型尺寸推算的保守包絡與擴張 AABB 掃掠；雨霧僅視覺效果；手把硬體尚未驗證。

0.3 版提供 GPS、氣壓、磁力、朝下測距、平面光達和光流的幾何或數學近似，可設定採樣率、共同延遲／丟包及個別故障。感測器影格與設定及故障事件保存於版本 3 紀錄；遙測 CSV 有 98 欄，另可匯出目前感測器 JSON 與光達點雲 CSV。同頁程式介面可控制並訂閱狀態，但不是網路服務或飛控協定橋接；重播時拒絕 API 查詢與命令，訂閱註冊仍可呼叫。飛控仍使用既有理想觀測，感測器故障不影響控制；沒有感測器融合、實體相機、地磁模型或校準保證。

0.4 版新增固定翼與 lift+cruise VTOL 的簡化模型、巡航四門及同頁 API 1.1，功能狀態以部分實作標示。固定翼預設由空中開始，返航於家點盤旋；懸停、近距離四門與垂直精準降落練習不適用固定翼。VTOL 巡航轉換最低高度 8 m。紀錄 schema 4／模型 0.4.0、119 欄 CSV，不接受舊版 1／2／3。飛行資料包含 `flight` 與 `controlSurfaces`；六種感測器仍獨立於飛控。參考 [PX4 氣動模型](https://github.com/PX4/PX4-SITL_gazebo-classic/blob/main/src/liftdrag_plugin/README.md)及 [JSBSim](https://github.com/JSBSim-Team/jsbsim)，模型並非實機校準；詳見[飛行模型說明](飛行模型說明.md)。

0.5 版提供簡化固定翼跑道起飛、中止及起降循環；一次瀏覽器循環已完成起飛、落地與停穩評分。教育跑道共用世界原點向北 N=0–200 m、E=±15 m，200 × 30 m 僅為模型假設；參考 [PX4 固定翼起飛](https://docs.px4.io/main/en/flight_modes_fw/takeoff)。課程僅限固定翼，需從地面起飛爬升再落地停穩兩秒，非訓練認證。API 1.2、紀錄 schema 5／模型 0.5.0、127 欄 CSV 已驗證匯出與重播；不接受舊版 1 至 4。

0.6 版新增同步 RGB、相機光軸平面深度、語意分類及獨立相機資料集，初步 GPU 與三影格瀏覽器資料集往返驗證已完成。影像不代表實體相機或校準模型；細節見[相機資料說明](相機資料說明.md)。飛行紀錄維持 schema 5／模型 0.5。

0.7 版提供本機 PX4 v1.17.0 四旋翼 SITL 閉環，模擬器以 MAVLink 傳送感測資料並接收執行器輸出，不等同地面站遙測或實體 HIL。其 WMM-2020 磁場與獨立 SITL 紀錄不同於內建感測器及 schema 5；瀏覽器已驗證起飛、暫停刷新後接回、紀錄匯出及降落；範圍與驗證見 [PX4 SITL 操作](PX4_SITL操作.md)。

0.8 版提供多層三維光達及 CSV／ASCII PCD 匯出；幾何僅涵蓋平地與訓練障礙包圍盒，非完整視覺場景、實機校準或 PX4 光達輸入。內建紀錄使用 schema 6，PX4 SITL 紀錄維持獨立版本 1；詳見[光達資料說明](光達資料說明.md)。

0.9 版提供本機場景及賽道編輯；目前涵蓋局部地形、障礙盒與航門，不是完整 GIS、任意網格或多人／社群服務。現行內建紀錄使用 schema 15、拒絕舊版 1–14；資料契約見[場景與賽道](場景與賽道.md)。

0.10 版 ArduCopter 4.7.2 本機 SITL 已完成原生飛行閉環與離線重播驗證，僅支援指定四旋翼。詳見 [ArduPilot SITL 操作](ArduPilot_SITL操作.md)。

0.11 版本機 ArduCopter SITL 航點任務已完成真實 AUTO 飛行及離線重播測試；內建四旋翼可從地面開始任務，固定翼須先完成跑道起飛。PX4 外部航點任務已通過兩圈原生 SITL 與獨立重播驗證；實體 HIL 尚未支援。詳見 [ArduPilot 航點任務](ArduPilot_航點任務.md)。

0.12 版 PX4 航點任務範圍及來源見 [PX4 航點任務](PX4_航點任務.md)，兩圈原生 SITL 與獨立重播已驗證。

0.14 版新增六、八旋翼配置，已測試飛行與資料往返；範圍、順序與限制見[多旋翼配置](多旋翼配置.md)。

0.15 版局部高度地形與真值 AGL 位置模式已完成瀏覽器飛行及獨立重播測試；範圍與限制見[地形與地面高度](地形與地面高度.md)。

0.16 版新增七步基礎飛行引導與模擬狀態程序檢核，已驗證瀏覽器飛行與獨立重播；詳見[基礎飛行教學](基礎飛行教學.md)。

0.17 版本機地面站橋接已以 MAVProxy 驗證 PX4 與 ArduCopter 任務、交接與失聯凍結；QGroundControl 已驗遙測，GUI 控制尚待驗證。範圍見[外部地面站](外部地面站.md)。

0.18 版可在本機匯入有限範圍 GeoTIFF 地形及地理原點；投影、資料範圍和飛行限制見[GeoTIFF 地理地形](GeoTIFF地理地形.md)。

0.20 版新增 1–8 架共用世界的混合機型、明確載具 ID、跨機感測遮擋與整批時間步；首次球形包絡相撞後停止全隊。這是瀏覽器內建模擬，尚無多套外部 SITL、尾流或經校準的碰撞反應；功能狀態由規劃改為部分實作。操作與格式見[多機模擬](多機模擬.md)。

0.21 版新增前向幾何雷達，支援多機相對距離變化與遮擋；因未模擬電波與材質反射，功能狀態為部分實作。詳見[雷達資料說明](雷達資料說明.md)。

0.22 版提供通用高塔及立面的實際相機拍攝檢查與每機進度；這是幾何觀測練習，不辨識缺陷或提供認證。詳見[設施巡檢](設施巡檢.md)。

0.23 版新增可通行橋下空間的通用橋梁範本及橋底拍攝目標，仍屬部分實作；幾何範圍及限制見[設施巡檢](設施巡檢.md)。
