# 飛行紀錄時間軸

0.24 版在匯入現行飛行 JSON 後顯示「重播時間軸」。先從「實驗紀錄」選擇「匯入紀錄重播」；上限仍為 128 MiB，資料只在本頁處理。匯入新檔前請保留目前需要的紀錄。

- 拖曳「紀錄影格」，或用首幀、上一幀、下一幀、末幀定位。滑桿可使用方向鍵、Home、End；旁邊顯示影格數與模擬時間。
- 在「時間（秒）」輸入目標，再按「跳至時間」。顯示不晚於目標時間的原始影格；超過範圍時停在首幀或末幀，無效輸入保留目前畫面。
- 依「事件類型」及「事件對象」篩選，再按上一事件或下一事件。可檢查起飛、任務、陣風、故障、場景、感測器設定、雲台及巡檢拍攝等已記錄的事件；巡檢事件顯示目標與原始結果。世界事件與各載具事件分別保留。

每次導覽都會暫停重播；按「播放重播」從選中影格繼續，支援 0.5×、1×、2×、4×。到末幀會停住，再播放則從頭開始。切到背景分頁會暫停。

時間軸顯示原始保留狀態，不重新推進物理或產生插值。同一時間步的事件可依原始順序逐一瀏覽，但共用該時間步最後保留的影格，不代表每個指令之間都有影格。若事件時間沒有獨立保留影格，定位至其後第一個保留影格。事件清單只涵蓋檔案中的事件，不會推測或補寫新的飛行事件。

向前或向後跳轉會還原該時刻的全機隊、場景、航線、雲台、感測器設定與量測，以及訓練和巡檢狀態。切換載具沿用共用時鐘；圖表僅顯示游標之前最多 400 筆該載具的狀態。感測器的取得時間、延遲與無效值仍取自原始紀錄；重播不會重新採樣。只有最後影格才顯示檔案的世界終止原因。

重播仍為唯讀，不能注入新指令、巡檢或重新解鎖。導覽不會修改來源 JSON，完整匯出仍包含整份紀錄。相機 RGB／深度／分類資料集獨立於飛行 JSON；時間軸不會憑空重建拍攝影像，跳轉時會清除目前相機預覽，既有資料集仍可另行選取檢視。

目前紀錄 schema 為 **21**，不接受版本 0–20；物理模型 **0.15.0**、場景 **7**、相機資料集 **5**、巡檢報告 **2**，同頁 API 為 **2.10**。近接量測及其時間、無效原因會隨感測器影格還原。此時間軸供內建飛行紀錄使用；PX4／ArduPilot 獨立版本 1 紀錄仍由本機工具離線重播，沒有在瀏覽器中轉換格式。

設計概念先對照 [ROS 2 rosbag2 的回放時間設計](https://github.com/ros2/rosbag2/blob/9e310a6dc4e8c6b52211b628b2bf6f0a4f89dc87/docs/design/rosbag2_playback_time.md)與[播放器服務說明](https://github.com/ros2/rosbag2/blob/9e310a6dc4e8c6b52211b628b2bf6f0a4f89dc87/README.md)。本專案沿用已安裝的原生瀏覽器控制項與現有記錄投影，不依賴或提供 ROS 2 播放器服務，也未複製其原始碼。

371 項測試已通過，含 36,001 個影格及 100,000 個事件的搜尋邊界測試。瀏覽器以先前實際拍攝的 537.19 秒、10,750 影格紀錄驗證逐幀、時間跳轉、同時間步拍攝事件與向前／向後還原巡檢進度；導覽後匯出的飛行 JSON 與巡檢報告均與原檔逐位元組相同。另以真正物理模型產生的四／六旋翼雙機紀錄驗證場景、風、雲台、感測器、課程與碰撞終止原因的還原；此雙機紀錄不包含 GPU 相機證據。摘要見[時間軸驗證資料](validation/replay-v024.json)。
