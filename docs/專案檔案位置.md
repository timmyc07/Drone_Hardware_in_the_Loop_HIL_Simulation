# 專案檔案位置

此專案的工作檔案統一放在 `Drone_Hardware_in_the_Loop_HIL_Simulation/`。在根目錄啟動網頁；下載、原始資料及其他開發版本放入根目錄內的 `local/`，不再另建平行的 `Drone_HIL_*` 資料夾。

| 位置（相對於專案根目錄） | 內容 |
| --- | --- |
| `web/`、`companion/`、`tools/`、`docs/` | 各版本的程式、測試與說明 |
| `local/downloads/browser/` | 瀏覽器下載的飛行紀錄、相機資料集、巡檢報告、點雲及場景；原檔名保留 |
| `local/downloads/installers/` | QGroundControl 安裝映像檔 |
| `local/downloads/releases/` | 歷次網站發佈壓縮檔 |
| `local/downloads/nist-research/` | NIST 官方指南、評分表及製作參考 PDF |
| `local/evidence/session/` | 各版本驗證資料、截圖、GeoTIFF 及原始紀錄，保留原子目錄 |
| `local/evidence/<功能版本>/` | 後續版本的原始影像、飛行紀錄、報告及驗證結果 |
| `local/tools/` | PX4、ArduPilot 完整原始碼與編譯品、Python 環境及 QGroundControl.app |
| `local/worktrees/` | 各版本的開發目錄，保留分支與未提交修改 |
| `local/temporary/` | 歷次診斷腳本、測試日誌與暫存修補檔 |
| `local/temporary/system-temp/` | 從系統暫存區收回的原生飛控執行資料及驗證產物，保留原資料夾名稱 |
| `local/migration/` | 搬移前清單、SHA-256 與完整性核對結果 |
| `local/cache/npm/` | 本次安裝網頁依賴所用的套件快取 |

`local/` 整體由 `.gitignore` 排除；原始飛行資料、下載工具與 `.env` 不會因一般 Git 提交而上傳。搬移清單也保留在本機。系統安裝的 Node.js、Xcode、Python 與共用快取仍由系統管理。

2026-11-05 再次核對後，已補收系統暫存區內 23 個專案資料夾及一份診斷腳本，共 94 個一般檔案（637,260,090 bytes），搬移前後 SHA-256 全數相符。另將 22 個指向舊 PX4 位置的連結修正為專案內的相對路徑。完整清單與核對結果位於 `local/migration/system-temp-*.json`；下載資料夾亦已檢查，未發現額外可識別的本專案下載。

PX4、ArduPilot 本機執行與四個原生驗證腳本，預設均在所執行專案的 `local/temporary/` 建立唯一目錄，不再預設寫入系統暫存區。從其他目錄啟動亦相同；驗證腳本仍接受明確指定的輸出路徑。瀏覽器匯出請存入 `local/downloads/browser/`。路徑建立使用 Node.js 標準函式庫，已依本機 **24.20.0** 的[官方檔案系統文件](https://nodejs.org/download/release/v24.20.0/docs/api/fs.html#fspromisesmkdtempprefix-options)核對；Context7 使用 24.x 索引，未提供 24.20.0 專屬索引。

## 已收納的本機工具

在飛控介面填入下列檔案對應的**完整絕對路徑**，不再使用舊 `/tmp/drone-*` 路徑：

- PX4：`local/tools/px4-v1.17.0/build/px4_sitl_default/bin/px4`
- ArduCopter：`local/tools/ardupilot-Copter-4.7.2/build/sitl/bin/arducopter`
- QGroundControl：`local/tools/QGroundControl.app`

`local/tools/px4-python/` 及 `local/tools/mavproxy-1.8.75/` 保留原有 Python 3.9.6 套件；啟動腳本路徑已依新位置修正。環境依賴本機 Xcode Python，不能直接搬到其他電腦使用。新建 ArduPilot 編譯環境可依操作文件使用 `local/tools/ardupilot-python/`。

原生飛控的既有編譯品與本機修補均保留；建置快取可能含舊絕對路徑，搬移後尚未重新編譯，重新建置前應重新設定建置目錄。歷史驗證檔與診斷腳本中的原始來源路徑保留作為紀錄。

QGroundControl 的安裝映像及可啟動的應用程式副本均已收納。確認程式已關閉、專案內副本與原掛載的 1,158 個檔案及 413 個連結完全一致後，已退出舊暫存掛載；下次從 `local/tools/QGroundControl.app` 開啟。

搬移方式依 Git **2.54.0** 的[官方 worktree 文件](https://github.com/git/git/blob/v2.54.0/Documentation/git-worktree.adoc)，使用 `git worktree move` 維持分支連結。Context7 未提供 2.54.0 的專屬索引，已另核對此精確版本的官方文件。
