# 測繪網格任務

0.25 版在「任務規劃」提供局部公尺座標的多邊形網格規劃。產生結果仍為既有的普通航點，不改變飛行模型、飛行紀錄版本或外部飛控協定。

## 操作

1. 展開「測繪網格」，選擇「繪製測繪區域」，依邊界順序點選地圖。也可用「新增區域頂點」及數值欄位建立區域；「載入範例區域」提供 16 × 16 m 矩形。
2. 設定間距、方向及基準面高度。角度相對北方順時針，0° 為南北向、90° 為東西向；「反轉航線」會交換整條路線的起終點。
3. 按「預覽測繪航線」，核對面積、航點數、長度與實際間距。青色實線是測繪航段，紫色虛線是連接路線；橙色為目前航點草稿。地圖會依數字輸入的區域與草稿自動放大範圍，最大 ±500 m。
4. 按「取代航點草稿」，再使用既有「套用任務」或「開始任務」。取代草稿本身不會送出飛行指令。「匯出路線 JSON」保存普通航點，不保存區域邊界或測繪設定。

各載具保留各自的本頁測繪草稿。更改區域、設定或飛行限制後必須重新預覽；重播時不可編輯，且不顯示實驗草稿覆蓋圖。尚未提供測繪計畫檔案匯入或跨頁儲存。

本機 PX4／ArduCopter 使用相同航點草稿及原有上傳、讀回核對與開始條件。這一版本未重新進行原生 SITL 測繪飛行或硬體驗證。固定翼須先完成跑道起飛，且可能無法跟隨過密的短航段。

## 幾何與限制

- 區域為 3–20 個頂點的單一簡單多邊形，可為凹形；不接受洞、自交、重複接觸、重複頂點及折回邊。座標必須為有限數值且位於 ±500 m。
- 間距 0.5–200 m，角度 0–180°。高度仍須符合目前載具家點的圍欄上限；本機飛控另有最低高度限制。高度不是離地高度，不提供沿途地形淨空檢查。
- 跨向寬度分成 `ceil(寬度 / 設定間距)` 份，掃描線位於各份中心，因此實際間距不大於設定值。區域邊緣沒有自動追加邊界航線；這不保證相機覆蓋率或重疊率。
- 每條掃描線保留所有內部區間，依蛇形順序排列。需要繞過凹口時，以多邊形頂點的可視圖求最短連接折線。此幾何路線包含邊界，不是考慮機體尺寸的禁飛區／避障路徑。
- 全部航段端點與連接頂點合計最多 50 個航點；超過時整體拒絕，不截斷。航點停留時間預設 0 秒，可在既有航點清單修改。
- 進入首點的航段、控制器的到達半徑與實際轉彎軌跡不保證留在區域內。可搭配同頁的[自動拍攝](相機資料說明.md)，但網格未整合相機覆蓋規劃；未提供攝影測量、缺陷辨識或實機精度保證。

使用 `1e-8` 數值容差處理幾何接觸；面積不大於 `1e-8 m²` 的退化區域拒絕。掃描交點直接內插原始邊線，避免旋轉往返的浮點誤差使邊界航點超出 ±500 m。

## 來源與驗證

依使用者要求先查找 GitHub，參考 QGroundControl 在 commit `36436db319c731b70ab25dd3178896c4c22c75f6` 的[測繪操作文件](https://github.com/mavlink/qgroundcontrol/blob/36436db319c731b70ab25dd3178896c4c22c75f6/docs/en/qgc-user-guide/plan_view/pattern_survey.md)與[SurveyComplexItem 原始碼](https://github.com/mavlink/qgroundcontrol/blob/36436db319c731b70ab25dd3178896c4c22c75f6/src/MissionManager/SurveyComplexItem.cc)。僅參考使用行為，未複製程式碼或新增依賴。

單元測試涵蓋斜角、凹口多區間、窄凹口的最短連接、嚴格邊界、無效輸入與草稿保護。瀏覽器實際網格飛行及離線重播摘要見 [0.25 驗證](validation/survey-v025.json)；本機原始證據保留於專案根目錄的 `local/evidence/survey-v025/`。
