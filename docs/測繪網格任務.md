# 測繪網格任務

0.25 版在「任務規劃」提供局部公尺座標的多邊形網格規劃。產生結果仍為既有的普通航點，不改變飛行模型、飛行紀錄版本或外部飛控協定。

## 操作

1. 展開「測繪網格」，選擇「繪製測繪區域」，依邊界順序點選地圖。也可用「新增區域頂點」及數值欄位建立區域；「載入範例區域」提供 16 × 16 m 矩形。
2. 設定間距、方向及基準面高度；或勾選「依相機與重疊率規劃」，填寫固定平面高度、航向與旁向重疊率。角度相對北方順時針，0° 為南北向、90° 為東西向；「反轉航線」會交換整條路線的起終點。
3. 按「預覽測繪航線」，核對面積、航點數、長度與實際間距。青色實線是測繪航段，紫色虛線是連接路線；橙色為目前航點草稿。相機模式的淡黃色矩形是首航點理想第一張足跡，不代表已拍照片。地圖會依數字輸入的區域與草稿自動放大範圍，最大 ±500 m。
4. 手動模式按「取代航點草稿」；相機模式按「套用航點與拍攝設定」，同時設定 NED 偏航為網格角度、俯仰 90°、橫滾 0°，以及距離自動拍攝設定。再開始任務，並在「感測器」開始自動拍攝。套用本身不會飛行或開始拍攝。套用設定的是雲台目標，實際姿態及高度仍需穩定；起飛時即開始拍攝會包含低空進場影像。「匯出路線 JSON」保存普通航點，不保存區域邊界或測繪設定。

各載具保留各自的本頁測繪草稿；相機規劃草稿不會持久保存。更改區域、設定或飛行限制後必須重新預覽；重播時不可編輯，且不顯示實驗草稿覆蓋圖。尚未提供測繪計畫檔案匯入或跨頁儲存。

本機 PX4／ArduCopter 使用相同航點草稿及原有上傳、讀回核對與開始條件。這一版本未重新進行原生 SITL 測繪飛行或硬體驗證。固定翼須先完成跑道起飛，且可能無法跟隨過密的短航段。

## 幾何與限制

- 區域為 3–20 個頂點的單一簡單多邊形，可為凹形；不接受洞、自交、重複接觸、重複頂點及折回邊。座標必須為有限數值且位於 ±500 m。
- 間距 0.5–200 m，角度 0–180°。高度仍須符合目前載具家點的圍欄上限；本機飛控另有最低高度限制。高度不是離地高度，不提供沿途地形淨空檢查。
- 跨向寬度分成 `ceil(寬度 / 設定間距)` 份，掃描線位於各份中心，因此實際間距不大於設定值。區域邊緣沒有自動追加邊界航線；這不保證相機覆蓋率或重疊率。
- 每條掃描線保留所有內部區間，依蛇形順序排列。需要繞過凹口時，以多邊形頂點的可視圖求最短連接折線。此幾何路線包含邊界，不是考慮機體尺寸的禁飛區／避障路徑。
- 全部航段端點與連接頂點合計最多 50 個航點；超過時整體拒絕，不截斷。航點停留時間預設 0 秒，可在既有航點清單修改。
- 進入首點的航段、控制器的到達半徑與實際轉彎軌跡不保證留在區域內。實際拍攝也可能包含進場與連接航段；任務完成後不會自動停拍，須手動停止。未提供地形自適應、實際重疊率保證、拼接、正射影像或實機校準。

使用 `1e-8` 數值容差處理幾何接觸；面積不大於 `1e-8 m²` 的退化區域拒絕。掃描交點直接內插原始邊線，避免旋轉往返的浮點誤差使邊界航點超出 ±500 m。

## 相機規劃（0.27）

使用目前相機設定與正下視固定平面估算。航向與旁向重疊率均為 0–95%；高度差 `h = 航線高度 - 平面高度` 必須嚴格介於相機近、遠裁切距離之間。水平視場角為 HFOV、影像寬高為 width 和 height 時，足跡寬 `W = 2h tan(HFOV/2)`、長 `L = W × height / width`，地面解析度 `GSD = W / width`；線距為 `W × (1 - 旁向重疊率)`，距離拍攝間距為 `L × (1 - 航向重疊率)`。計算結果須符合既有線距及拍攝間距範圍，不會自動夾值。

摘要以航線長度除以拍攝間距估計張數，不含進場與實際誤差，並非上界。僅內建模擬模式可套用相機規劃；資料集仍受 30 張或 24 MiB 上限及每秒最多兩張限制，套用時張數上限設為剩餘可容納數。詳見[相機資料說明](相機資料說明.md)。
