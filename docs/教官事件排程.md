# 教官事件排程

「教官排程」工作區可在內建多機模擬中預先安排最多 64 筆事件。這是同頁操作工具，沒有學員權限隔離、遠端角色、班級管理或正式訓練認證；外部 SITL 與實機不提供此排程。八種虛擬感測器故障仍不改變內建飛控的理想狀態觀測。

## 操作

1. 在「教官排程」新增事件，選擇事件類型、目標載具及參數；也可載入 GPS 故障範例。時間是自世界起點起算的模擬秒數，須對齊 0.005 秒，且每筆都必須晚於目前世界時間。最多 1800 秒。
2. 依時間排序並預覽驗證，再按「套用並重設教官紀錄」。相同時間依列順序執行；載具必須存在，馬達及推進器依機型檢查。套用只武裝排程，不會起飛或啟動模擬；按開始或繼續後才隨世界時鐘觸發。
3. 查看實際執行狀態與逐筆結果，必要時匯出執行報告。取消只取消未來事件，已注入的故障或風不會自動恢復；請手動清除、設定恢復事件或重設世界。

暫停或巡檢拍攝鎖定期間世界時鐘不前進；模擬速度、畫面更新率與目前選中的載具不改變觸發 tick。每一物理步後於指定 tick 執行。執行失敗會停止後續事件並暫停世界，已執行結果保留；碰撞、地形覆蓋、儲存或時間上限終止會取消剩餘事件。重設世界會清除已套用計畫與報告，介面草稿保留但不自動套用；需要報告時先匯出。

支援 GPS、氣壓計、磁力計、朝下測距、光達、光流、雷達、近接測距故障與恢復；升力馬達效率（索引從 0 開始）、固定翼／VTOL 推進器效率、連線中斷／恢復、清除載具故障、陣風及全域風（速度 0–30 m/s、方向 0–360 度）。「清除載具故障」僅清除機體故障，不清除感測器故障或風。

連線恢復不會自動撤銷已啟動的安全返航或降落。連線正常後可手動切回位置或姿態模式，再開始新的飛行；取消排程也不會改變目前的飛行模式。碰撞、地形終止或資料／時間上限後須先重設，才能套用新計畫。排程錯誤後可手動繼續模擬，但停止的排程不會自行恢復。

計畫可匯入或匯出 JSON（匯入上限 64 KiB）；執行報告只能匯出。飛行紀錄只保存實際觸發的普通命令，不保存未來計畫或教官報告；重播採既有同 tick 最後影格規則，不重新執行排程。資料結構見[同頁程式介接](程式介接.md)。

設計參考 [PX4 故障注入與恢復文件](https://github.com/PX4/PX4-Autopilot/blob/5468dd100a69796dfdea8d99921d091f188799e4/docs/en/debug/failure_injection.md)；本功能未使用 PX4 或 MAVLink 注入，其支援範圍以本頁為準。
