# 本機外部地面站（0.17 版）

飛控通訊與被動健康回報的判讀方式見[飛控健康診斷](飛控健康診斷.md)；命令送出後仍需確認飛控實際狀態。
本機 companion 可將 PX4 v1.17.0 或 ArduCopter 4.7.2 的 MAVLink 資料轉給本機地面站，並在明確交接後接受受限控制。已以原生軟體飛控與 MAVProxy 完成閉環驗證；此為軟體模擬，不是實體 HIL。公開網站不直接提供此橋接。

啟動方式見 [PX4 SITL](PX4_SITL操作.md) 或 [ArduPilot SITL](ArduPilot_SITL操作.md)。在本機頁面飛控介接區的「本機地面站橋接」設定地面站 UDP 埠（預設 14550），先啟用橋接、確認收到地面站心跳，再依介面切換控制權。這些選項在本機管理介面設定，不需寫入 `.env`。橋接啟用與收到心跳是兩個不同狀態。

控制權只能在已驗證飛控、收到新鮮飛控心跳、地面穩定且已上鎖、沒有進行中命令或任務交易時交接；轉交地面站前還需地面站新鮮心跳。地面站持有控制時，網頁不再發送飛行或任務命令，但保留暫停、繼續和停止；切換背景分頁或中斷網頁連線不會自動暫停。地面站心跳失聯 5 秒會使模擬故障凍結；請先匯出需要的紀錄。

橋接只綁定本機 loopback；地面站程式自身的監聽設定由該程式決定。QGroundControl 5.1.5 的 UDP 實作固定綁定所有 IPv4 介面，設定 localhost 目標不會改變其監聽範圍。網頁內部 MAVLink 身分為 system 255/component 191，外部地面站為 255/190。

心跳及讀取訊息可使用 MAVLink 1；控制訊息須使用 MAVLink 2，且只接受已知 common／ardupilotmega CRC 及受限命令；拒絕簽章封包、強制解鎖、參數寫入、FTP、直接執行器及 HIL 注入。目前任務傳輸僅支援一般航點（missionType 0），未提供圍欄／rally 計畫傳輸。任務上下載依受限交易處理，地面站接管時網頁不宣稱已核對其航線。獨立 SITL 紀錄維持版本 1，附加保存地面站原始事件；內建飛行紀錄現為 schema 15，外部格式不受影響。

MAVProxy 1.8.75 可作本機測試地面站，例如指定 `--master=udpin:127.0.0.1:14650 --source-system=255 --source-component=190 --target-system=1 --target-component=1 --mav20`，再於介面設定對應目標埠。MAVProxy 1.8.75 的 PX4 `mode MISSION` 有 tuple 轉換問題；PX4 模式切換可用 `long 176 1 4 4`，並依飛控回報確認。ArduCopter GUIDED 使用其對應模式與相對高度命令；應先等待飛控心跳識別出 ArduCopter，否則地面站可能採用錯誤機型的模式表。不可把 PX4 的 AMSL 起飛參數直接套到 ArduCopter。

QGroundControl 5.1.5 官方應用程式已收到心跳與遙測，並顯示地圖、模式、GPS 與電池；完整 GUI 飛行控制尚未驗證。網頁持有控制權時其任務／rally 請求會被拒絕，可能出現 rally 逾時。參考 [QGroundControl UDP 原始碼](https://github.com/mavlink/qgroundcontrol/blob/v5.1.5/src/Comms/UDPLink.cc)、[MAVProxy 啟動文件](https://ardupilot.org/mavproxy/docs/getting_started/starting.html)及 [PX4 地面站起飛流程](https://github.com/mavlink/qgroundcontrol/blob/v5.1.5/src/FirmwarePlugin/PX4/PX4FirmwarePlugin.cc)。

使用 stock MAVProxy 1.8.75 對兩種原生飛控均驗證：只讀時拒絕控制，交接後上傳、下載並執行四航點任務及落地，再交回網頁於同一 session 完成相同航線，最後驗證心跳失聯 5 秒觸發指定故障並凍結模擬時間。PX4 紀錄為 92.916 秒、1859 樣本與 23212 個執行器輸入；ArduCopter 為 148.442 秒、2970 樣本與 148442 個輸入；兩者獨立重播誤差均為 0。

可依序執行原生驗證（需另行準備上述版本的飛控及 MAVProxy，不由測試自動安裝）：

```sh
node companion/verify-ground-station.mjs px4 /absolute/path/to/px4 /absolute/path/to/mavproxy.py /absolute/px4-proof
node companion/verify-ground-station.mjs ardupilot /absolute/path/to/arducopter /absolute/path/to/mavproxy.py /absolute/ardupilot-proof
```

驗證使用本機 UDP 14650，請先停止占用同一埠的測試地面站，並以不同輸出目錄保留各次結果。PX4 網頁重新上傳會在地面上鎖後先正常切到 HOLD、清除舊航線並確認，再傳送及讀回新航線；中途失敗不會保留舊任務的已驗證狀態。ArduCopter 暖機時可能正常拒絕解鎖，驗證只會等待後重試一般解鎖，不會略過飛控健康檢查。
