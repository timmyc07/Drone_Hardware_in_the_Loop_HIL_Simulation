# 同世界載具跟飛

跟飛讓內建模擬中的多旋翼或懸停 VTOL，使用位置控制器追隨同一世界的另一架真實模擬載具。領航機與跟隨機均須解鎖並起飛；跟飛不會自動起飛。固定翼與外部飛控不支援跟飛，VTOL 必須完成懸停才能啟動，跟飛中不能轉換巡航。

1. 在「飛行器」管理機隊，建立至少兩架載具並確認起點不重疊；套用機隊會重設整個實驗。
2. 選擇跟隨機，開啟「管理模擬參數」的「載具跟飛」，選領航機與偏移，按「套用跟飛設定」。此按鈕獨立套用，不會套用其他管理草稿或重設實驗。
3. 分別選取兩架載具，解鎖並起飛。切回跟隨機，按「開始跟飛」；畫面顯示領航機、狀態、兩機距離與位置目標。
4. 按「停止並保持位置」結束跟飛。停跟後不會自動重新啟動，狀態會顯示停止原因。

世界座標的 X、Y 分別為北、東；領航機航向座標的 X、Y 分別為前、右。高度差以共同基準面的領航機高度為基準，向上為正。各偏移可設定 −100 至 100 公尺，最大距離為 1 至 500 公尺。失去跟飛條件時可設定保持位置或返航；航向可保持、跟隨領航機航向或面向領航機。操作員按停止時保持位置。

領航機不可是自身，也不可形成循環跟隨。兩機間距及目標會受限制與安全條件檢查；跟飛不代表能繞過障礙或保證不碰撞。實驗重設保留已套用設定，但不自動開始跟飛。錄製與回放會顯示對應影格的設定與狀態，回放時設定與操作為唯讀。

領機來源使用同一共同時間步開始前的模擬真值，不使用 GPS 估測或網路訊息。跟飛使用領機水平速度前饋，再經既有 3 m/s 速度、3 m/s² 加速度及姿態控制限制；航向座標轉彎不加入偏移旋轉的切向速度前饋，受限時會暫時落後。自身圍欄、失聯與電量保護優先；可另外啟用幾何碰撞預防，但它也不保證不碰撞。跨機碰撞仍會鎖停整個世界。

現行格式為錄影 22、模型 0.16.0、API 2.11、CSV 222 欄；場景 7、相機資料集 5、原生 SITL 紀錄格式 1 不變。舊內建錄影 1–21 需用對應舊版開啟，不會自動轉換。614 項測試、實際飛行與原生回歸見 [follow-me-v035.json](validation/follow-me-v035.json)。參考 [PX4 v1.17.0 Follow-Me](https://github.com/PX4/PX4-Autopilot/blob/v1.17.0/docs/en/flight_modes_mc/follow_me.md)與 [ArduPilot Follow](https://ardupilot.org/copter/docs/follow-mode.html)的功能概念，未複製其程式碼；目前不提供網路 Follow Target、隊形避碰或實機校準。
