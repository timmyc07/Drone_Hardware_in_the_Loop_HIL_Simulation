# 外部飛控健康與起飛診斷（0.19 版）

本機 PX4 v1.17.0 或 ArduCopter 4.7.2 連線後，「飛控介接」分開顯示通訊準備、飛控健康回報及近期訊息。通訊身分、參數與心跳確認，只表示通訊準備；它不代表飛控允許解鎖或起飛。此功能只讀取飛控健康資料，不關閉檢查、不強制解鎖，也不以植物模型真值冒充飛控健康或估測結果。

健康摘要來自已驗證飛控的 `HEARTBEAT` 與 `SYS_STATUS`，齡期以本機單調時鐘自接收時計算。飛控身分未知、工作階段未運行、資料缺失或超過 5000 ms 時，預檢結論顯示未知；斷線後保留的值標為斷線時歷史快照，不是正在更新的狀態。新鮮且已驗證的心跳若回報已解鎖，可顯示「已解鎖」；這只表示當前解鎖狀態，不表示重新通過預檢。

針對本專案固定支援的版本，PX4 v1.17.0 使用 `SYS_STATUS` 的 health 第 28 位回報目前模式可否解鎖，不要求 enabled 位元同時設定；ArduCopter 4.7.2 若該預檢 enabled 位元未設定，顯示「預檢位元未啟用」，不能當成通過，也不代表所有檢查都被關閉。預檢位元正常仍不保證下一次解鎖或起飛命令會成功，請依命令回覆及後續飛控解鎖、模式和高度狀態確認。各版本的行為可查 [PX4 v1.17.0 SYS_STATUS](https://github.com/PX4/PX4-Autopilot/blob/v1.17.0/src/modules/mavlink/streams/SYS_STATUS.hpp)、[ArduPilot Copter-4.7.2 GCS](https://github.com/ArduPilot/ardupilot/blob/Copter-4.7.2/libraries/GCS_MAVLink/GCS.cpp) 與 [MAVLink SYS_STATUS 定義](https://mavlink.io/en/messages/common.html#SYS_STATUS)。

「查看原始健康診斷」可展開 `present`、`enabled`、`health` 與啟用但未健康的 32 位旗標。後者計算為 `enabled & ~health`，不額外與 `present` 相交；未知旗標以位元編號顯示，第 31 位仍按無號 32 位數呈現。最近最多 20 筆 `STATUSTEXT` 為歷史回報並附齡期和嚴重度，不等於現在仍存在的故障。分段訊息標示為未組合片段；不能單獨以 UTF-8 解碼時保留原始十六進位資料，不猜測其內容。參見 [MAVLink STATUSTEXT](https://mavlink.io/en/messages/common.html#STATUSTEXT) 及 [ArduPilot 起飛前檢查](https://ardupilot.org/copter/docs/common-prearm-safety-checks.html)。

QGroundControl 可能依 Events 健康報告、預檢位元或設定完成度與感測器狀態採不同判斷；本頁不完整重現這些資料，因此不保證徽章一致，也無法由單一旗標斷定 QGroundControl 顯示原因。其分支可查 [QGroundControl 5.1.5 狀態指示器](https://github.com/mavlink/qgroundcontrol/blob/v5.1.5/src/Toolbar/MainStatusIndicator.qml) 與 [Vehicle SYS_STATUS 處理](https://github.com/mavlink/qgroundcontrol/blob/v5.1.5/src/Vehicle/Vehicle.cc)。在一次臨時 QGroundControl 遙測記錄中，391 筆、約 139.1 秒資料的 `enabled & ~health` 唯一位元為遙控接收器 `0x00010000`，但 `present` 未包含該位元；這可解釋該次 fallback 判斷的條件，並不代表所有未就緒狀態都由遙控接收器造成。當時 PX4 `COM_RC_IN_MODE=4` 不需要 RC，主控台與目前模式回報也可能與 fallback 判斷不同。

診斷只存在目前即時 `controller.health`；現有飛行紀錄不保存健康快取，重播不提供歷史健康結論。0.19 驗證時內建格式為 schema 11；現行多機版已升為 schema 14，外部 SITL 紀錄仍為版本 1。已完成本機 PX4 瀏覽器健康顯示、正常起降及暫停過期狀態驗證；ArduPilot 另以原生 Session API 驗證真實預檢拒絕、暖機後起飛、降落與自動上鎖，未以 QGC GUI 發送這些命令。摘要見[驗證資料](validation/controller-health-v019.json)。

MAVLink 解碼使用專案鎖定的 [node-mavlink 2.3.0](https://www.npmjs.com/package/node-mavlink/v/2.3.0)。Context7 未索引此確切版本；已核對 npm 套件及其 `gitHead` `6ca789c494f9ed94818d06a485915b3f7680216c`，未以其他版本文件替代。

ArduCopter 預設不持續輸出此診斷所需的 SYS_STATUS，companion 在運行或啟動時每秒以標準 REQUEST_MESSAGE 請求一次，不更改健康檢查或飛行參數。交給外部地面站後仍保留這項唯讀查詢；網頁的內部心跳、任務與控制流程不會因此重新接管。暫停、故障或停止後不再排入內部遙測查詢，避免在模擬時鐘停止時累積請求。
