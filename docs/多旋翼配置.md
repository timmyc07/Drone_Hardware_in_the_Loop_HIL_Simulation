# 多旋翼配置（0.14 版）

本批新增 `hexarotor` 六旋翼和 `octorotor` 八旋翼，保留 `quadrotor` 四旋翼。六、八旋翼均已完成地面起飛及四航點飛行、個別馬達效率故障與紀錄往返測試；它們是未經實機校準的教育近似，不代表具有故障容錯、失效馬達重新分配或單槳失效後安全降落的能力。

六旋翼採 X 型等間隔配置，馬達 M1 起的機體方位角為 30° + 60° × i；八旋翼為 22.5° + 45° × i，i 由 0 起，從機首向右順時針排列。M1 為 CCW、產生正偏航反扭矩，後續 CW／CCW 交替。此順序是本模擬器的內部約定，不是 PX4 或 ArduPilot 的馬達通道對應。

FRD 機體座標以質心為原點，旋翼位置 r = (x, y, 0)，向上推力 F = (0, 0, −T)，所以 r × F = (−yT, xT, 0)，再加上對應旋向的偏航反扭矩。幾何概念參考 [ArduPilot SITL 馬達配置](https://github.com/ArduPilot/ardupilot/blob/Copter-4.7.2/libraries/SITL/SIM_Frame.cpp) 與 [PX4 執行器與 FRD 幾何](https://github.com/PX4/PX4-Autopilot/blob/main/docs/en/config/actuators.md)。[PX4 馬達故障恢復說明](https://github.com/PX4/PX4-Autopilot/blob/main/docs/en/config/motor_failure_recovery.md) 描述的偵測與重新分配並未因此自動具備。

飛行模型版本為 0.10.0，既有四旋翼數值路徑不變。飛行 JSON 使用 schema 15，拒絕舊版 1–14；CSV 為 174 欄（原 167 欄後追加 7 欄雷達摘要），前置 `vehicle_id`、`world_tick`；原 144 欄後追加 `lift_motor_channel_count` 與 M5–M8 的正規化轉速、PWM、效率共 13 欄，再追加地形相關 7 欄，無通道以空字串表示。固定翼仍保留四個未使用的升力通道欄位，不代表裝有四個升力旋翼。相機資料集為版本 5，場景為版本 6；雲台動作契約不變。PX4／ArduPilot 外部 SITL 仍只支援四旋翼，獨立版本 1 紀錄不變，原四旋翼紀錄可使用其獨立離線重播。

六旋翼飛行紀錄為 1,759 筆、87.865 秒，八旋翼為 2,018 筆、100.845 秒；兩者經事件獨立重跑，最大位置差小於 6×10⁻¹⁵ m，四元數及馬達差均小於 10⁻¹⁵。八旋翼相機影格姿態與最後飛行樣本一致。八旋翼畫面重播已核對最後樣本（100.84499999998 秒，顯示 01:40.84）、八組馬達及第八顆效率 50%，控制維持唯讀；見[驗證資料](validation/multirotor-v014.json)，該批歷史紀錄不能匯入現行格式。
