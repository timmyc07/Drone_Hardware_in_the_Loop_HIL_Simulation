# 六向近接測距

0.28 版的感測器工作台顯示所選載具六向近接量測。每個方向是一條從質心發出的射線，以機體 FRD 座標表示：前 +X、後 −X、右 +Y、左 −Y、上 −Z、下 +Z。距離不是機身表面間隙。此功能僅供觀察與警示，不控制飛行、不執行避障，也不提供安全保證。

管理區可調整採樣率、最小及最大距離、雜訊與警示門檻；感測器共用延遲及丟包設定，並可個別注入近接故障。近接使用獨立隨機序列，不改變既有七個感測通道的隨機序列。射線使用局部地形、障礙的軸對齊包圍盒及其他載具的球形包絡，不是逐網格量測，也未經實機校準。外部 PX4／ArduPilot SITL 不提供此量測。

`tooClose` 為真且對應距離為 `null` 表示首個物體比最小測距更近；它不是無回波。無回波只表示射線未取得距離，不代表安全。啟動、故障、丟包與過期資料顯示資訊不足；介面會顯示量測時刻、齡期及警示門檻。

可匯出獨立 JSON 或 CSV。JSON 的 `format` 為 `flight-lab-proximity`，版本為 1；`worldTick` 是匯出時的世界觀測 tick，`reading.time` 是量測取得時刻，兩者意義不同。每筆量測包含姿態、最小／最大距離、門檻、六個距離及六個 `tooClose` 旗標，連同有效性與原因保存。程式可透過 `getSensors(id).proximity` 查詢，或呼叫 `exportProximityData(id, format = "json")` 取得 `{format, sourceVehicleId, exportWorldTick, time, text}`。內建飛行紀錄 schema 22 保存各載具量測；遙測 CSV 共 222 欄，包含近接、電池供電與碰撞預防欄位。

紀錄使用無損六欄資料列保存採樣時間、原因、位置、四元數、六個距離及盲區位元；全空距離與精確單位四元數使用縮短表示，讀取時完整還原。量程與門檻依該時刻的感測器設定重建，沒有四捨五入或刪除採樣。紀錄格式 21 及更早不會自動轉換，需用對應舊版開啟；現行模型為 0.16.0、場景為 7、相機資料集為 5。

設計概念參考 [AirSim distance sensor 文件](https://github.com/microsoft/AirSim/blob/1ca93f6f77e4e8a39b2b241c1fe2764da4d7dd41/docs/distance_sensor.md)，未複製其程式或加入依賴。驗證摘要見 [proximity-v028.json](validation/proximity-v028.json)。
