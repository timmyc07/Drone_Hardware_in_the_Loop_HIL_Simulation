# 基礎飛行教學（0.16 版）

本課是內建模擬的七步引導練習；它檢查模擬狀態，不代表實機檢查、飛行資格或認證。適用四、六、八旋翼及完全懸停的 VTOL；固定翼與外部 SITL 不支援。

訓練選單選擇教學只會準備顯示開始按鈕；按「從地面開始教學」才建立並播放新的地面實驗。如現有資料未保存，依介面提示確認；此操作不改瀏覽器儲存的地面起始偏好。透過 API 或場景編輯器直接套用教學時，當前機體須在家點地面、已上鎖且狀態正常，不符合時原子拒絕。圍欄半徑須至少 10 m、高度至少 3 m，為飛行修正保留空間；風、模型參數與操控仍可能觸發圍欄。飛行畫面持續顯示目前步驟及提示，請依提示操作。

依序完成：

1. 起飛前模擬狀態檢查，連續 2 秒。
2. 解鎖並維持 1 秒。
3. 在家點升至 2 m，維持 1 秒。
4. 定點懸停 5 秒。
5. 移動至北 8 m、東 0 m、高 2 m，維持 3 秒。
6. 回到家點，維持 3 秒。
7. 降落、上鎖並維持 2 秒。

各步須由連續模擬狀態證實，按下按鈕本身不等於完成；每次更新最多前進一步，時間間隔超過 0.1 秒會重置該步持續計時。最低持續時間合計 17 秒，實際飛行還需要轉換時間。失敗得分 0，完成得分 1000；此分數僅供本課練習。

目前飛行紀錄為 schema 19、模型 0.13.0、場景版本 7、CSV 202 欄與 API 2.8；原課程代碼 0–6 不變，教學為 7。參考 [ArduPilot SITL 飛行教學](https://github.com/ArduPilot/ardupilot_wiki/blob/master/dev/source/docs/copter-sitl-mavproxy-tutorial.rst)、[ArduPilot 起飛前檢查](https://github.com/ArduPilot/ardupilot_wiki/blob/master/common/source/docs/common-prearm-safety-checks.rst) 及 [PX4 落地偵測](https://github.com/PX4/PX4-user_guide/blob/main/en/advanced_config/land_detector.md)，本課使用獨立的簡化模擬條件。

瀏覽器八旋翼練習於模擬時間 104.23 秒完成七步，落地上鎖得 1000 分；125.05 秒紀錄含 2502 個樣本，4 倍速重播回到 7/7 且維持唯讀。獨立以 200 Hz 重跑，所有訓練欄位一致，位置最大差約 1.78×10⁻¹⁵ m。該次驗證使用的舊版紀錄不適用目前 schema 19 解析器。
