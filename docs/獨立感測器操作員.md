# 獨立感測器操作員站

0.31 操作員站將飛行員的主站與感測器操作員分成獨立分頁。兩者共用同一個內建模擬世界與主站實際相機渲染結果，不建立另一個模擬世界。523 項測試、三機雙站操作及重播結果見[驗證摘要](validation/operator-v031.json)。

在主站的「操作員站」工作區啟用工作階段，再開啟操作員視窗。每個工作階段以 UUID 辨識，只接受一個操作員客戶端；操作員可綁定載具，飛行員切換所選載具不會改變該綁定。此功能只適用同一瀏覽器、設定檔、來源與儲存分區；主站須保持開啟。重設世界、切換重播或外部來源會關閉工作階段。

操作員可檢視主站同一渲染器產生的 RGB、深度及語意分類資料，並設定雲台模式與目標；最大轉速沿用載具設定。指令回覆與作用 tick 可用來辨識結果。最新遙測與影像曝光時的 metadata 分開顯示，不能假定兩者時間相同。可匯出單張資料集 JSON 與 RGB PNG；資料集格式為版本 5。

即時影像預設關閉，啟用後最多每秒請求一次，並以背壓避免請求堆積。失聯逾 10 秒時停止控制，保留舊圖並標明失聯；重新連線不補送舊指令。主站「允許背景運行」預設關閉；若已開啟，操作員失聯且主站隱藏時仍會自動暫停。

主站明確關閉連線時，操作員頁會停止重連；請由主站啟用新工作階段並開啟新連結。影像預覽只保留最後一張，需自行匯出保存。測試瀏覽器在雙頁操作時持續回報主站可見，因此隱藏分頁的背景排程與自動暫停僅完成程式路徑審查，未宣稱已完成端到端實測。

這是本機模擬練習，不是網路多人系統、帳號驗證或安全權限隔離；同源可信任程式可存取通訊機制。模型與影像未經實機校準，也不構成認證。

## 格式與參考

現行飛行紀錄為 schema 20（拒絕 1–19）、模型 0.14.0，場景版本 7、資料集版本 5、遙測 CSV 215 欄；同頁 API 2.9 見[程式介接](程式介接.md)。

跨視窗通訊採瀏覽器原生 [BroadcastChannel](https://developer.mozilla.org/en-US/docs/Web/API/Broadcast_Channel_API)：同源且受儲存分區限制，訊息使用結構化複製。連線與失聯需應用程式處理；[HTML 標準](https://html.spec.whatwg.org/multipage/web-messaging.html)描述通道訊息及以回應與逾時判斷對端是否仍存在。另一種點對點方式為 [MessageChannel](https://developer.mozilla.org/en-US/docs/Web/API/MessageChannel)，跨視窗交付通道時須核對來源；此版本無須新增套件。[Vite 8.3.5 多頁建置文件](https://github.com/vitejs/vite/blob/v8.3.5/docs/guide/build.md#multi-page-app)說明獨立頁面建置方式。

開源參考包括 [QGroundControl](https://github.com/mavlink/qgroundcontrol)（專案列出 Apache-2.0 與 GPL-3.0 授權，具體使用須核對檔案授權）及其[雲台控制文件](https://docs.qgroundcontrol.com/master/en/qgc-user-guide/setup_view/joystick.html)，以及 MIT 授權的跨分頁通訊專案 [TabJS](https://github.com/buildwithdarsh/TabJS)。這些為技術參考，未因此宣稱功能或精度相同。
