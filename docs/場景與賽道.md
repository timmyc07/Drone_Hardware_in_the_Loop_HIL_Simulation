# 場景與賽道（0.9 版）

場景由同一份資料描述環境、地面障礙盒及訓練航門；它不是任意網格編輯器或社群分享服務，練習也不是認證或防作弊系統。

## 場景與編輯

`SceneSpec` 包含長度 1–80 字元的 `name`、`environment`、最多 50 個 `obstacles`、`terrain`、`geography` 與最多 50 個 `customGates`。障礙使用既有 NED 地面軸對齊包圍盒欄位。自訂航門包含 `north`、`east`（各 -500 至 500 m）、`altitude`（0.25–500 m）、`yaw`（-π 至 π rad）與 `radius`（0.25–100 m）。五種機型都可選擇自訂課程；選中時至少要有一門，未選中時仍保留自訂門清單。

編輯介面支援障礙盒與航門的新增、刪除、數值編輯、俯視放置及拖曳，航門可排序。草稿與已套用場景須分別顯示；完整場景經驗證後原子套用，失敗不應改動目前飛行或已套用場景。天氣調整不應覆寫自訂障礙。視覺、碰撞、LiDAR 與相機共用障礙資料；航門只作評分標記與相機場景，不是實體環形碰撞物件。

場景與自訂航門由所有載具共用；訓練課程及進度分別保存在各載具的 setup 與狀態中。航門依序、按正向穿越平面評分；同一時間步若高速穿過多門，以各平面交點時間依序判定。只改天氣或未使用的自訂門清單不重設目前成績；有效課程或其門序改變才重計。

## 匯入、記錄與重播

獨立場景 JSON 格式為 `{format: "flight-lab-scene", version: 4, frame: "NED", units: "m", scene}`，匯入上限 512 KiB；匯入前驗證，不合法資料不應覆蓋草稿或已套用場景。內建飛行紀錄使用 schema 13，不相容舊版 1–12；物理模型為 0.9.0，PX4 SITL 的獨立紀錄仍為版本 1。場景版本 4 必須包含 terrain 與 geography（非地理場景為 null），課程不再存於場景；拒絕版本 1–3；內建紀錄保存初始場景及完整場景變更事件，重播時依採樣時間檢查航門數及下一門。重播介面唯讀，可匯出當時場景；程式 API 在重播或 PX4 模式拒絕場景操作。

概念參考 [AirSim 物件 API](https://github.com/microsoft/AirSim/blob/main/PythonClient/airsim/client.py)、[Webots 場景樹](https://github.com/cyberbotics/webots/blob/master/docs/guide/the-user-interface.md)及 [FPV Web 賽道編輯器](https://github.com/rachmataditiya/fpv-web)。本專案沿用自己的資料結構，不複製上述引擎程式。

先前單機版本的場景與重播驗證見[歷史驗證資料](validation/scene-v0.9.0.json)；該資料使用舊格式，不能匯入現行版本。0.20 多機瀏覽器驗證已完成。

地理地形及原點會隨版本 4 場景保存；套用不同地理原點會重設實驗。參見[GeoTIFF 地理地形](GeoTIFF地理地形.md)。
