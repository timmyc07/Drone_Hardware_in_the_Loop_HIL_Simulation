# 瀏覽器程式介接

`window.flightLab` 是同一頁面可信任 JavaScript 可使用的非同步介面，版本 `1.2`。它不開啟網路服務，不提供跨來源訊息介面，亦不是 PX4、MAVLink 或 ROS 橋接。頁面內有執行權限的程式均可呼叫此介面；不要在此頁執行不可信任程式碼。

重播模式下傳送至模擬器的查詢與命令會被拒絕，須先離開重播模式；訂閱註冊本身仍可呼叫。除同步訂閱註冊外，命令與查詢方法回傳 Promise，驗證失敗或操作無法執行時會拒絕；`setTransition("hover")` 會切換到位置保持；任務載入仍須另外選擇任務模式。輸入、輸出及訂閱通知均以 `structuredClone` 複製，不可複製的值會引發錯誤。參見 [MDN structuredClone](https://developer.mozilla.org/en-US/docs/Web/API/Window/structuredClone)：這是瀏覽器 Web API，而非獨立飛控協定。

```js
try {
  const state = await window.flightLab.getState();
  console.log(state.snapshot.position, state.running, state.timing);
  const sensors = await window.flightLab.getSensors();
  console.log(sensors.gps, sensors.lidar);

  await window.flightLab.setMission([
    { north: 5, east: 0, altitude: 3, hold: 1 },
    { north: 5, east: 5, altitude: 3, hold: 1 },
  ]);
  await window.flightLab.setMode("mission");
  await window.flightLab.play();
} catch (error) {
  console.error("模擬器拒絕操作：", error.message);
}
```

航點使用北、東、高度，單位為公尺；`hold` 為停留秒數。任務載入與切換模式是兩個不同命令，位置與航點仍需符合模擬器的驗證及圍欄。

## 方法

| 方法                               | 用途                                                                                                                                                          |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `getState()`                       | 取得 `{snapshot, sensors, setup, running, timing}` 的目前狀態；`timing` 的執行統計欄位為展平結構，包含 `realTimeFactor`。                                     |
| `getSensors()`                     | 取得目前完整感測器資料。                                                                                                                                      |
| `setTargets(value)`                | 設定 `altitude`（m）、`roll`／`pitch`（rad）、`yawRate`（rad/s）與翼機 `airspeed`（m/s）目標。                                                                |
| `setMode(value)`                   | 設定飛行模式，例如 `position`、`mission`、`rtl` 或 `land`。                                                                                                   |
| `setTransition(value)`             | VTOL 在 `hover`／`cruise` 間轉換；巡航須已升至至少 8 m，返回懸停會進入位置保持。                                                                              |
| `setPusherFault(efficiency)`       | 固定翼／VTOL 的巡航推進效率，範圍 0–1；四旋翼拒絕此操作。                                                                                                     |
| `setPositionTarget(value)`         | 設定 `{north, east, altitude}` 位置目標。                                                                                                                     |
| `setMission(points)`               | 設定航點陣列。                                                                                                                                                |
| `takeoff()`、`abortTakeoff()`      | 起飛與中止指令；固定翼地面使用 `takeoff` 模式，其他機型拒絕此模式。                                                                                           |
| `play()`、`pause()`                | 開始或暫停模擬。                                                                                                                                              |
| `reset({config, scenario, setup})` | 重設模擬；只接受這三個可選欄位。省略 config／scenario 時沿用目前值；省略 setup 時保留環境與感測器設定，但清空任務並回到姿態模式；機型改變時練習回到自由飛行。 |
| `setSensorConfig(value)`           | 重新設定感測器並清除感測器故障；省略的感測器欄位回到預設值。                                                                                                  |
| `setSensorFault(sensor, failed)`   | 設定指定感測器故障，`failed` 為布林值。                                                                                                                       |
| `exportRecording()`                | 回傳原始紀錄物件，不觸發下載。                                                                                                                                |
| `subscribe(callback)`              | 註冊狀態通知並回傳取消訂閱函式。                                                                                                                              |

```js
const unsubscribe = window.flightLab.subscribe((state) => {
  console.log(state);
});
// 不再需要時：unsubscribe();
```

感測器資料包含 `gps`、`barometer`、`magnetometer`、`rangefinder`、`lidar`、`opticalFlow` 和 `faults`。各筆讀數有模擬時間 `time`、`valid` 與 `reason`；無效或無回波時相關值可能為 `null`。LiDAR 讀數包含 `rangesM`、`positionNed`、`quaternion`、`angleStartRad`、`angleStepRad`、`minM` 與 `maxM`；這些是用於重建點的射線資料，並非校準過的實體點雲。坐標採 NED，姿態為四元數。感測器預設採樣率為 GPS 5 Hz、LiDAR 10 Hz，其餘 20 Hz；狀態通知最多約 20 Hz，與物理模型 200 Hz 不同。暫停時模擬時間不推進。

版本 5 錄製的 `sensorFrames` 保存各感測器影格，並記錄感測器設定及故障事件供重播；可在介面匯出目前感測器 JSON 或光達點雲 CSV。錄製上限為 30 分鐘或約 96 MiB，匯入上限為 128 MiB；不接受舊版 1／2／3／4。

感測器是獨立於飛控的簡化虛擬觀測；感測器故障不影響控制，飛控仍使用既有理想觀測。沒有感測器融合、實體相機、地磁模型或實體校準保證，不能視為真實感測器或位置估測器。參數範圍、故障與飛行狀態限制以實際模擬器驗證為準。

`getState().snapshot` 的 `flight`、`propulsion` 與 `controlSurfaces` 提供空速、攻角、翼面失速、轉換狀態、推進槳及舵面資料。固定翼預設由空中開始；可使用簡化地面跑道起飛及中止，返航為家點盤旋；機型與控制器皆屬未校準近似。版本 5 遙測 CSV 有 127 欄。CSV 的 `airframe_code` 依序為四旋翼 0、固定翼 1、VTOL 2；`transition_code` 為懸停 0、巡航 1；`transition_phase_code` 為懸停 0、加速轉換 1、巡航 2、減速轉換 3。

`reset({config: {...完整設定, startOnGround: true}})` 可使三種機型由地面零速、未解鎖開始，重設不自動播放。`snapshot.runway` 包含 `onRunway`、`weightOnWheels`、`distanceRemainingM`、`crossTrackM`、`rotationSpeedMps`、`takeoffPhase`、`abortReason`、`brake`；階段為 `idle`、`runup`、`roll`、`rotate`、`climb`、`complete` 或 `aborted`。跑道與流程均為未經實機校準的教育近似。

`setMode("takeoff")` 僅供地面固定翼；`abortTakeoff()` 僅在固定翼起飛進行中有效。地面中止會切推力、制動並上鎖；空中由飛行員中止時切至位置保持並以至少 30 m 為高度目標，安全因素引發的空中中止則切至降落。起降練習中止時 `training.reason` 為 `takeoff-aborted`，墜毀則為 `crashed`。

CSV `navigation_mode_code`：姿態 0、位置 1、任務 2、返航 3、降落 4、起飛 5；`takeoff_phase_code`：idle 0、runup 1、roll 2、rotate 3、climb 4、complete 5、aborted 6；`takeoff_abort_reason_code`：無 0、pilot 1、pusher-failure 2、runway-end 3、runway-excursion 4、insufficient-airspeed 5、safety 6。
