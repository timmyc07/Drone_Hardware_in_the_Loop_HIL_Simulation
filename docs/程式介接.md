# 同頁程式介接

`window.flightLab` 是同一頁面可信任 JavaScript 可使用的非同步介面，版本 `2.8`。它不開啟網路服務，也不是 PX4、MAVLink 或 ROS 橋接；本機飛控服務另見 [PX4 SITL 操作](PX4_SITL操作.md)與 [ArduPilot SITL 操作](ArduPilot_SITL操作.md)。頁面內有執行權限的程式皆可使用此介面，請勿執行不可信任程式。輸入、回傳值及訂閱通知使用 `structuredClone` 複製；除訂閱註冊外，方法皆回傳 Promise。操作失敗時 Promise 會拒絕。

多載具共用場景、風與模擬時鐘，飛行命令和載具查詢都必須明確傳入 `vehicleId`，不依畫面選擇推斷。ID 為 1–32 個字元，以英數開頭，後續可用英數、點、底線或連字號。單機同樣需要 ID。以下例子假設目前存在 `drone-1`：

```js
const api = window.flightLab;
const id = "drone-1";
const world = await api.getWorldState();
const vehicle = await api.getState(id);
const sensors = await api.getSensors(id);
await api.setMode(id, "position");
await api.setPositionTarget(id, {
  north: 5,
  east: 0,
  altitude: 3,
  altitudeReference: "datum",
});
await api.play();
```

載具查詢有 `getState(id)`、`getSensors(id)`、`getGimbal(id)`、`captureCamera(id)` 及 `exportLidarPointCloud(id, format)`、`exportRadarData(id, format)`、`exportProximityData(id, format)`、`getInspectionReport(id)`；相機目前要求該載具也在畫面選中。光達匯出格式為 `"csv"` 或 `"pcd"`，預設 PCD；雷達為 `"json"` 或 `"csv"`，預設 JSON；近接同樣支援 `"json"` 或 `"csv"`，預設 JSON。`getSensors(id).proximity` 取得近接量測；`exportProximityData(id, format = "json")` 回傳 `{format, sourceVehicleId, exportWorldTick, time, text}`，其中匯出世界 tick 是觀測時刻，量測時刻為 `reading.time`。格式與限制見[六向近接測距](近接測距.md)。`captureInspection(id, targetId)` 拍攝並檢查，回傳巡檢報告，要求載具為目前畫面選中機體。載具控制有 `setTargets(id, value)`、`setMode(id, value)`、`setPositionTarget(id, value)`、`setMission(id, points)`、`takeoff(id)`、`abortTakeoff(id)`、`setTransition(id, value)`、`setPusherFault(id, efficiency)`、`setSensorConfig(id, value)`、`setSensorFault(id, sensor, failed)`、`setGimbal(id, settings)`。各指令仍受機型、飛行階段與驗證條件限制；設定航點不等於開始任務。

自動拍攝可用 `startAutomaticCamera(id, {mode, interval, maxFrames})`、`stopAutomaticCamera()` 與 `getAutomaticCamera()`；開始時 ID 必須為目前選中載具。`mode` 為 `"time"`（0.5–300 秒）或 `"distance"`（0.25–500 公尺），`maxFrames` 為 1–30 的整數。三個方法回傳目前狀態小物件，包含 `active`、`pending`、`phase`、`vehicleId`、`settings`、`saved`、`reason` 與 `last`。開始僅適用內建模擬，具體拍攝條件及資料集限制見[相機資料說明](相機資料說明.md)。既有 `captureCamera(id)` 仍更新預覽但不加入資料集。

`getWorldState()` 取得世界及目前選擇投影；`getScene()`、`setScene(scene)`、`play()`、`pause()`、`resetWorld(worldConfig)`、`exportRecording()`、`getCameraConfig()`、`setCameraConfig(partial)` 是全域操作，不傳載具 ID。地形或地理原點變動須用 `resetWorld`，不能在既有錄製中 `setScene` 改動；介面的場景編輯會確認後重設全隊。`resetWorld` 原子驗證整份世界設定，成功後重設所有載具與實驗紀錄。設定格式為 `{scene, wind: {speed, direction}, vehicles: [{id, name, config, spawn, home, scenario, setup}]}`；起點 `spawn` 包含 `north`、`east`、離地高度 `altitude` 及弧度 `heading`，`home` 為 `[north, east]`。每架 `config.wind` 和 `config.windDirection` 必須等於共同風設定；每架 `setup` 保存自己的模式、任務、感測器、雲台和訓練課程。可先由 `getWorldState()` 回傳的 `worldConfig` 複製並編輯後送入。載具 1–8 架，須通過地形、圍欄與初始碰撞檢查。

```js
const stop = api.subscribe((state) => {
  console.log(state.world.tick, state.activeVehicleId);
});
// 不再需要時：stop();
```

重播及外部飛控模式拒絕同頁 API 的模擬查詢與命令；訂閱註冊本身仍可呼叫。外部 PX4／ArduPilot 僅支援單架且使用獨立本機服務。內建模式的感測器為簡化虛擬觀測，故障不改變內建控制器觀測；相機、光達和雲台的限制見[相機資料說明](相機資料說明.md)、[光達資料說明](光達資料說明.md)與[雲台說明](雲台說明.md)。

`setPositionTarget` 的 `altitudeReference` 為 `"datum"` 或 `"agl"`；AGL 僅支援位置模式下的多旋翼與完全懸停 VTOL。航點使用 datum，直接設定高度目標會切回 datum。固定翼起飛、中止與轉換操作受實際狀態約束，詳見[飛行模型說明](飛行模型說明.md)。

內建飛行紀錄為 schema 19、模型 0.13.0；初始 `world` 保存機隊和共享場景，`samples` 與 `sensorFrames` 按世界 tick 保存各載具，事件標記受影響的載具 ID。重播由紀錄重建，拒絕舊 schema 1–18。遙測 CSV 每架每樣本一列，共 202 欄（原 199 欄後追加開路電壓、供電轉速比例與功率不足旗標），前兩欄為 `vehicle_id`、`world_tick`；飛行紀錄上限為 30 分鐘或約 96 MiB，JSON 匯入上限為 128 MiB。相機資料集獨立保存。座標採 NED（北、東、下）及機體 FRD（前、右、下），GPS 垂直基準代碼為未指定 0、橢球高 1、正高 2。

## 教官事件排程

全域方法 `applyInstructorPlan(plan)`、`cancelInstructorPlan()`、`getInstructorStatus()` 回傳目前狀態。碰撞、地形終止或資料／時間上限後拒絕套用新計畫，須先重設；狀態查詢及取消仍可操作。套用前須取消已武裝計畫；所有事件 tick 必須大於目前 `world.tick`。計畫恰為 `{name, events}`，名稱去除首尾空白後非空且最多 80 字元，事件 1–64 筆、依 tick 非遞減排列；tick 為 1–360000 的整數，每 tick 0.005 秒，同 tick 依列順序。事件只允許下列欄位：

```js
{tick, vehicleId, type: "sensorFault", value: {sensor, failed}}
{tick, vehicleId, type: "fault", fault: "motor", value: {index, efficiency}}
{tick, vehicleId, type: "fault", fault: "pusher", value: {efficiency}}
{tick, vehicleId, type: "fault", fault: "link", value: {lost}}
{tick, vehicleId, type: "clearFaults"}
{tick, vehicleId, type: "gust"}
{tick, type: "wind", value: {speed, direction}}
```

`sensor` 為 `gps`、`barometer`、`magnetometer`、`rangefinder`、`lidar`、`opticalFlow`、`radar` 或 `proximity`；`failed`、`lost` 為布林值。效率為 0–1，馬達索引從 0 開始且依機型檢查；固定翼無升力馬達，推進器僅固定翼及 VTOL。風速為 0–30 m/s，方向為 0–360 度。載具 ID 必須存在。

狀態為 `{phase, plan, appliedAtTick, nextIndex, receipts, reason}`；`phase` 為 `idle`、`armed`、`complete`、`cancelled` 或 `error`，每筆 receipt 為 `{index, tick, status, error}`，狀態為 `applied` 或 `failed`。計畫 JSON 為 `{format: "flight-lab-instructor-plan", version: 1, plan}`，匯入上限 64 KiB；報告 JSON 為 `{format: "flight-lab-instructor-report", version: 1, ...status}`，僅供匯出。操作與終止行為見[教官事件排程](教官事件排程.md)。

## NIST 基礎操控練習

`startNistTrial(vehicleId, {durationSeconds})` 綁定地面上的多旋翼或 VTOL；秒數須為 30–1800 的整數，場景須啟用 `nistLane`，且使用零高度平地和 `geography: null`。`captureNist(vehicleId, slotId)` 使用指定拍攝槽；`scoreNistImage(vehicleId, {slotId, value})` 對已拍攝影像人工評 0 或 1；`scoreNistLanding(vehicleId, {phase, value})` 在已降落時人工評分，`phase` 為 `position`、`left`、`right`，上限依序為 2、1、1。`endNistTrial(vehicleId)` 結束，`getNistReport(vehicleId)` 查詢報告。每槽只能拍攝及評分各一次，結束後可補評既有影像，但不能新增拍攝或降落；新練習須重設。

報告版本 1 使用 `flight-lab-nist-report`，包含 `definition` 與 `session`；後者包含載具、時間、影像 metadata、SHA-256、分數、降落與終止原因，不含原始影像。飛行紀錄保存 NIST 事件，`recordingNistState` 支援重播回看。操作、核對方式及人工判讀限制見 [NIST 基礎操控](NIST基礎操控.md)。

## 獨立感測器操作員

`setOperatorGimbal(vehicleId, fullSettings)` 設定指定載具的完整雲台設定，並產生可辨識來源的 `operatorGimbal` 紀錄事件。操作員站橋接只接受模式與目標，最大角速度沿用該載具既有設定；這個橋接不提供飛行控制。影像、連線與安全限制見[獨立感測器操作員](獨立感測器操作員.md)。

## 電池與推進供電

`getState(id).battery` 包含 `openCircuitVoltage`（V）、`motorSpeedScale`（0–1）與 `powerLimited`（布林值），以及既有電量、負載電壓、電流、功率及耗電量。`motors` 和推進器 `motor` 是含一階延遲的滿電參考轉速需求；實際正規化轉速為該值乘上 `motorSpeedScale`，推力比例為其平方。外部飛控紀錄也必須帶現行 `modelVersion`；模型與通道範圍見[電池與推進供電](電池與推進供電.md)。

格式 19 的內建飛行 JSON 將每個樣本的 `battery` 無損打包為固定 11 元素陣列，順序為 `[soc, voltage, current, power, usedWh, remainingSeconds, low, critical, openCircuitVoltage, motorSpeedScale, powerLimited]`；三個旗標仍為布林值。驗證後及 API 查詢回傳具名欄位物件。原生 SITL 紀錄維持具名物件；CSV 末三欄為 `battery_open_circuit_voltage_V`、`battery_motor_speed_scale_fraction`、`battery_power_limited_boolean`，旗標輸出 0／1。
