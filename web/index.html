任務規劃 MISSION PLANNER

點選地圖新增航點；北方朝上，東方朝右，航點高度使用基準面。座標範圍 ±50 m。

測繪網格

依序點選地圖或輸入座標建立區域，再預覽並取代航點草稿。

高度使用基準面；僅產生航線，未含避障、自動拍照或覆蓋率保證。進入首點的航段與實際轉彎不保證留在區域內。

區域頂點（可編輯）

圖例：青色實線為測繪航段，紫色虛線為連接路線。

套用任務會切換至任務模式；開始任務會同時啟動模擬。

訓練場 PRACTICE

獨立練習與模擬評分，不代表正式認證。

尚未開始

教學從家點地面、上鎖狀態開始，建立新實驗並先進行起飛前檢查。適用多旋翼與懸停 VTOL；不代表正式認證。

須由地面起跑，完成爬升，再落地、上鎖並停穩 2 秒才得分；空中起始不符合條件。此練習不代表正式認證。

雨與霧僅影響畫面；風向與亂流可在管理參數中設定。

場景與賽道編輯 SCENE EDITOR

障礙盒會影響碰撞與測距；訓練門僅作評分標記，不會阻擋光達。

已套用

匯入 GeoTIFF 地形

檔案只在本機處理，不會上傳。預覽後可明確套用並重設實驗。

尚未選擇地形檔案。

地形高度網格

程序地形高度為基準面公尺，邊界與跑道、家點保護區須為平地；匯入 DEM 保留真實坡度。障礙盒及訓練門使用基準面座標。

場景物件

選取物件

設施巡檢 INSPECTION

使用實際相機拍攝，以 25 個取樣點檢查構圖與遮擋、解析度、距離及朝向；僅供模擬練習，不辨識缺陷或提供認證。

載入後請至場景編輯套用；地形及地理原點會保留。橋下拍攝可將雲台俯仰設為 −90°（向下為正）。

尚無巡檢目標。

感測器工作台 VIRTUAL SENSORS

合成感測器與故障僅供觀察，不驅動理想化飛控；數值未經實機校準。

機載相機

影像、深度與分類取自同一次拍攝；相機資料集需另行匯出，不包含在飛行紀錄中。

雲台：等待狀態

尚未拍攝

分類圖例依場景物件區分；影像為模擬資料。

前向雷達

固定朝機體前方的幾何量測；速度為相對距離變化：負值靠近、正值遠離。橙色回波表示靠近，青色表示遠離或零。此模型不包含電波、材質反射或目標識別，資料不控制飛行器。

LiDAR 多層掃描（俯視投影）

顏色表示掃描層：低仰角偏藍、高仰角偏橙；射線偵測地形、訓練障礙盒及其他飛行器的保守包圍範圍，不含建物裝飾、天氣、材質、強度或多重回波。資料不驅動內建飛控，也不輸入 外部飛控。

飛控介接 PX4 / ARDUPILOT SITL

本機軟體飛控與植物模型閉環；畫面呈現植物模型真值，不是實體硬體 HIL 或飛控估測值。

此頁不直接連接本機服務。請先建置後執行 npm run companion，再開啟 本機 Flight Lab。

本機地面站橋接

僅本機迴圈 UDP。橋接啟用與收到地面站心跳為不同狀態；交給地面站後網頁僅保留暫停、繼續與停止。 切換控制權或關閉橋接前須在地面上鎖；接管須先收到地面站心跳。
