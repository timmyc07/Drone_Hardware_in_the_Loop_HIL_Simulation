開始你的第一個實驗

  1. 選擇「穩定懸停」，按「開始模擬」。
  2. 調整高度、滾轉或俯仰，觀察 3D 與姿態曲線。
  3. 切換階躍或陣風情境，比較控制響應。
  4. 在管理參數調整模型、控制器與感測故障；使用相同種子重現結果。
  5. 從「實驗紀錄」匯出 CSV 分析，或匯出 JSON 後再次匯入重播。

姿態指令會造成水平移動；位置與任務模式使用簡化控制。固定翼無法懸停，其位置與返航模式以盤旋保持，降落採固定航向進場。控制器使用理想化姿態觀測；虛擬 IMU 的雜訊是每次取樣的標準差倍率，尚未對應真實感測器。切到背景分頁會自動暫停，避免隱藏節流被誤認為實時結果。

關閉 3D 渲染仍可持續模擬。數值模型為 200 Hz；實驗資料每模擬秒記錄 20 筆，最長 30 分鐘後自動暫停。
