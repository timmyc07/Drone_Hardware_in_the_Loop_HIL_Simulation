任務規劃 MISSION PLANNER

點選地圖新增航點；北方朝上，東方朝右，航點高度使用基準面。座標範圍 ±50 m。

套用任務會切換至任務模式；開始任務會同時啟動模擬。

訓練場 PRACTICE

獨立練習與模擬評分，不代表正式認證。

尚未開始

須由地面起跑，完成爬升，再落地、上鎖並停穩 2 秒才得分；空中起始不符合條件。此練習不代表正式認證。

雨與霧僅影響畫面；風向與亂流可在管理參數中設定。

場景與賽道編輯 SCENE EDITOR

障礙盒會影響碰撞與測距；訓練門僅作評分標記，不會阻擋光達。

    4.

    5. 
        
  5. 從「實驗紀錄」匯出 CSV 分析，或匯出 JSON 後再次匯入重播。

        IMU
        的雜訊是每次取樣的標準差倍率，尚未對應真實感測器。切到背景分頁會自動暫停，避免隱藏節流被誤認為實時結果。
