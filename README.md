# Drone Flight Lab

瀏覽器中的無人機飛行模擬器，可操作飛行、規劃航點、練習任務並記錄與回放資料。線上入口：[Drone Flight Lab](https://drone-flight-lab-reikous.chen-yu-ting0718-05.chatgpt.site)。

0.23 版新增[橋梁底面巡檢與高架障礙](docs/設施巡檢.md)；0.22 版新增[設施巡檢拍攝練習](docs/設施巡檢.md)；0.21 版新增[前向幾何雷達](docs/雷達資料說明.md)；0.20 版新增[共用世界多機模擬](docs/多機模擬.md)，同頁可操作 1–8 架混合機型；0.19 版新增[外部飛控健康診斷](docs/飛控健康診斷.md)；0.18 版新增本機 GeoTIFF 地理地形，詳見[GeoTIFF 地理地形](docs/GeoTIFF地理地形.md)；0.17 版新增本機外部地面站橋接，詳見[外部地面站](docs/外部地面站.md)；0.16.1 版改善起飛入口與離地高度顯示；0.16 版新增七步基礎飛行教學；0.15 版新增局部地形；0.14 版新增六、八旋翼，並提供理想三軸雲台、機載相機與固定翼跑道起飛；各機型均為未經實機校準的教育近似。

目前有瀏覽器內建軟體模擬，以及本機 PX4／ArduPilot SITL 閉環；皆未經實機校準。原研究計畫的 Unity 方案是歷史提案；瀏覽器模擬器是目前實作的另一種方案。

## 本機啟動

需要 Node.js 22.12 以上及 npm。使用 Three.js 0.187.0 與 Vite 8.3.5，內建模擬不需要後端或 `.env`；外部 SITL 則需本機 companion 與受支援的飛控執行檔。

```sh
npm ci
npm run dev
```

依終端機顯示的本機網址開啟。其他指令：

```sh
npm test          # 執行測試
npm run build     # 建立正式版本
npm run preview   # 預覽已建立的版本
```

0.10 版 ArduCopter SITL 已完成原生飛行閉環與離線重播驗證，詳見 [ArduPilot SITL 操作](docs/ArduPilot_SITL操作.md)。本機 PX4 軟體飛控閉環的準備與操作請見 [PX4 SITL 操作](docs/PX4_SITL操作.md)；公開網站本身不連接本機飛控服務。

0.11 版本機 ArduCopter 支援經讀回核對的航點任務與自動降落，詳見 [ArduPilot 航點任務](docs/ArduPilot_航點任務.md)；PX4 外部任務已通過兩圈原生 SITL 與獨立重播驗證，詳見 [PX4 航點任務](docs/PX4_航點任務.md)。內建四旋翼可由地面開始任務並起飛，固定翼需先完成跑道起飛。

## 使用方式

新瀏覽器預設從地面開始；按 3D 畫面上方的「起飛並開始」會啟用跟隨視角並開始起飛，畫面左上顯示離地高度。右側「起飛」也會開始模擬。若已儲存空中起始偏好，請在管理區開啟地面起始並按「套用設定」，再按起飛；若要空中起始則關閉該設定。切到背景分頁時模擬會自動暫停，返回後按「繼續模擬」。中止後可按「繼續模擬」觀察制動停止，不會自動再次起飛。

- 在 3D 畫面上方選擇目前控制的載具；「管理機隊」可新增、移除或修改起點與家點，套用會重設全隊。各機共用時鐘，切換查看不重設飛行。
- 在飛行管理區選擇姿態、位置、任務、返航或降落模式，使用解鎖、上鎖、起飛、返航與降落按鈕；位置模式可設定北、東及高度目標。勾選鍵盤／手把操控後，WASD 控制姿態，方向鍵控制偏航與升降。實體手把尚未驗證。
- 在任務區點選地圖或新增航點，設定座標及高度，套用後開始任務。圍欄限制水平半徑和高度，觸發後使用簡化返航處置。
- 在訓練區選擇[基礎飛行教學](docs/基礎飛行教學.md)、自由飛行、定點懸停、四門航線、精準降落、巡航航線或固定翼跑道起降循環。固定翼支援自由飛行、巡航航線與跑道起降循環，不能使用懸停、近距離四門或垂直精準降落練習。練習使用模擬時間及簡化規則計分，不代表正式訓練認證。場景提供固定環境、時間、霧與雨的視覺設定。
- 飛行管理區可設定馬達效率或模擬斷訊，再以清除故障恢復；管理區可調整模型和電池等參數，設定儲存在瀏覽器 localStorage。
- 模擬以 20 Hz 記錄，最多 30 分鐘或約 96 MiB；匯入檔案上限 128 MiB。可匯出 174 欄遙測 CSV、目前感測器 JSON 或光達點雲 CSV，也可匯出完整 JSON 並匯入重播。紀錄版本 15 保存全機隊、各機飛行與舵面資料、感測器影格、設定和帶載具 ID 的事件，供重播使用；不接受舊版 1 至 14 紀錄。
- 管理區可設定 GPS、氣壓計、磁力計、朝下測距、多層光達、光流和雷達的採樣率、共同延遲與丟包，並注入個別感測器故障。同頁面 JavaScript 可用 [`window.flightLab` 程式介面](docs/程式介接.md)查詢、控制及訂閱狀態。

0.6 版提供機載 RGB、平面深度與語意分類資料；相機資料集獨立於飛行紀錄，格式與限制見[相機資料說明](docs/相機資料說明.md)。已驗證三張影格的瀏覽器匯出、匯入、選取及再次匯出。

0.8 版提供多層光達與 CSV／ASCII PCD 匯出；參見[光達資料說明](docs/光達資料說明.md)。內建紀錄使用 schema 15；PX4 與 ArduPilot SITL 各有獨立版本 1 紀錄。

0.9 版提供場景與賽道編輯：可編輯障礙盒及有序航門，資料格式與限制見[場景與賽道](docs/場景與賽道.md)。

0.13 版三軸雲台使用機體或 NED 世界方向目標、角度與角速度限制，詳見[雲台說明](docs/雲台說明.md)。瀏覽器三影格拍攝及資料集往返已驗證；外部 SITL 使用固定機體預設，不接收飛控雲台指令。

[多旋翼配置](docs/多旋翼配置.md)說明四、六、八槳幾何及目前驗證範圍；外部 SITL 仍限四旋翼。

## 模型與限制

模型版本 0.10.0 使用 NED 世界座標、FRD 機體座標與四元數，六自由度剛體以 RK4、200 Hz 在 Worker 運行。馬達推力來自轉速平方並含轉速延遲；PWM 是合成輸出。慣量由質量及臂長推算，阻力使用線性近似，地面可使用局部高度網格，見[地形與地面高度](docs/地形與地面高度.md)。

位置與姿態控制使用模擬狀態及可加入的雜訊，不是 GPS 或 EKF；IMU 包含雜訊、延遲與丟包設定；七種虛擬感測器獨立於飛控，感測器故障不影響控制，沒有感測器融合。電池以電量線性開路電壓與 Thevenin 壓降近似，電壓下降不會直接降低馬達推力。核心模型預設從空中開始，瀏覽器新設定預設為地面起始；提供地面起始及簡化跑道起飛／中止，返航後於家點盤旋。VTOL 轉入巡航前須升至至少 8 m。固定翼氣動、失速、家點進場及 VTOL 轉換均為簡化近似；家點落地在無風及 3 m/s 東風、南風測試完成，風會改變接地位置，並非精準跑道降落。VTOL 已測試 12 m 懸停至巡航再返回懸停；模型及安全處置尚未以實機校準驗證。詳見[飛行模型說明](docs/飛行模型說明.md)。

固定場景障礙使用依機型設定的保守包絡與擴張軸對齊包圍盒判定碰撞，並非逐網格碰撞。FPV 畫面及雨霧是視覺效果；內建模擬感測器均為幾何或數學近似，沒有實體相機、地磁模型或校準保證；PX4 SITL 磁場另使用 PX4 WMM-2020 查表。跨機碰撞與 CPU 測距使用依機型尺寸推算的保守球形包絡，首次相撞後停住世界；沒有撞擊反彈或尾流。多層光達模擬局部地形、訓練障礙包圍盒及其他載具包絡，不涵蓋完整場景或實機校準。實際飛行不應依賴此模擬器的精度或得分。

0.23 版的 360 項自動測試涵蓋橋下通行與巡檢、保守碰撞邊界、低速氣流角度、五機共用世界、重播、物理、資料邊界、Worker 與本機橋接；全部通過；這不代表實機校準、實體手把或硬體在迴路已驗證。

## 專案結構

- `web/sim.js`、`web/aerodynamics.js`：剛體、翼面、控制、航行、故障與感測模型。
- `web/training.js`、`web/input.js`：練習評分與操控輸入。
- `web/sensors.js`、`web/api.js`：虛擬感測器與同頁程式介面。
- `companion/`：本機 PX4／ArduPilot SITL 橋接、驗證及離線重播。
- `web/world.js`、`web/peer-geometry.js`：共用世界、載具 ID、整批時間步及跨機包絡。
- `tools/replay-world.mjs`：從紀錄重跑全機隊並核對物理與感測結果。
- `web/worker.js`：模擬排程與記錄；回放由 `web/main.js` 讀取已記錄狀態。
- `web/scene.js`、`web/main.js`、`web/style.css`：3D 場景及操作介面。
- `web/dem-import.js`、`web/dem-worker.js`、`web/geography.js`：有界 GeoTIFF 解碼、地理來源與本地座標。
- `web/capabilities.js`、`web/recording.js`、`web/tests/`：功能目錄、記錄格式與測試。
- `docs/`：功能盤點、原研究及硬體規劃。
