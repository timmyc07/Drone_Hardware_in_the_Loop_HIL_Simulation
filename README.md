# Drone Flight Lab

瀏覽器中的四軸飛行模擬器，可操作飛行、規劃航點、練習任務並記錄與回放資料。線上入口：[Drone Flight Lab](https://drone-flight-lab-reikous.chen-yu-ting0718-05.chatgpt.site)。

目前是軟體模擬，不是硬體在迴路：沒有實體飛控、MAVLink 或實機校準。原研究計畫的 Unity 方案是歷史提案；瀏覽器模擬器是目前實作的另一種方案。

## 本機啟動

需要 Node.js 22.12 以上及 npm。使用 Three.js 0.187.0 與 Vite 8.3.5，不需要後端或 `.env`。

```sh
npm ci
npm run dev
```

依終端機顯示的本機網址開啟。其他指令：

```sh
npm test          # 執行測試
npm run build     # 建立正式版本
npm run preview   # 預覽已建立的版本
```

## 使用方式

- 在飛行管理區選擇姿態、位置、任務、返航或降落模式，使用解鎖、上鎖、起飛、返航與降落按鈕；位置模式可設定北、東及高度目標。勾選鍵盤／手把操控後，WASD 控制姿態，方向鍵控制偏航與升降。實體手把尚未驗證。
- 在任務區點選地圖或新增航點，設定座標及高度，套用後開始任務。圍欄限制水平半徑和高度，觸發後使用簡化返航處置。
- 在訓練區選擇自由飛行、定點懸停、四門航線或精準降落。練習使用模擬時間及簡化規則計分，不代表正式訓練認證。場景提供固定環境、時間、霧與雨的視覺設定。
- 飛行管理區可設定馬達效率或模擬斷訊，再以清除故障恢復；管理區可調整模型和電池等參數，設定儲存在瀏覽器 localStorage。
- 模擬以 20 Hz 記錄，最多 30 分鐘或約 96 MiB；匯入檔案上限 128 MiB。可匯出 98 欄遙測 CSV、目前感測器 JSON 或光達點雲 CSV，也可匯出完整 JSON 並匯入重播。紀錄版本 3 保存感測器影格、設定和故障事件，供重播使用；不接受舊版 1 或 2 紀錄。
- 管理區可設定 GPS、氣壓計、磁力計、朝下測距、平面光達和光流的採樣率、共同延遲與丟包，並注入個別感測器故障。同頁面 JavaScript 可用 [`window.flightLab` 程式介面](docs/程式介接.md)查詢、控制及訂閱狀態。

## 模型與限制

模型版本 0.3 使用 NED 世界座標、FRD 機體座標與四元數，六自由度剛體以 RK4、200 Hz 在 Worker 運行。馬達推力來自轉速平方並含轉速延遲；PWM 是合成輸出。慣量由質量及臂長推算，阻力使用線性近似，地面為平面。

位置與姿態控制使用模擬狀態及可加入的雜訊，不是 GPS 或 EKF；IMU 包含雜訊、延遲與丟包設定；新增六種感測器獨立於飛控，感測器故障不影響控制，沒有感測器融合。電池以電量線性開路電壓與 Thevenin 壓降近似，電壓下降不會直接降低馬達推力。模型及安全處置尚未以實機校準驗證。

固定場景障礙使用 0.25 m 包絡與掃掠軸對齊包圍盒判定碰撞，並非逐網格碰撞。FPV 畫面及雨霧是視覺效果；感測器均為幾何或數學近似，沒有實體相機、地磁模型或校準保證。平面光達不是完整三維光達。實際飛行不應依賴此模擬器的精度或得分。

## 專案結構

- `web/sim.js`：物理、控制、航行、故障與感測模型。
- `web/training.js`、`web/input.js`：練習評分與操控輸入。
- `web/sensors.js`、`web/api.js`：虛擬感測器與同頁程式介面。
- `web/worker.js`：模擬排程與記錄；回放由 `web/main.js` 讀取已記錄狀態。
- `web/scene.js`、`web/main.js`、`web/style.css`：3D 場景及操作介面。
- `web/capabilities.js`、`web/recording.js`、`web/tests/`：功能目錄、記錄格式與測試。
- `docs/`：功能盤點、原研究及硬體規劃。
